## Section 1: Visual Identity Statement

### One-Line Visual Rule

> 常态战场是可读的战术地图，释放瞬间是像素的暴力爆炸——视觉强度的两级跳跃，就是"压迫与释放"在视觉上的直接翻译。

### Supporting Principles

#### C1. 常态可读性铁律
*锚定支柱：闪避即武器*

在常态战斗中（非释放帧），角色位置、朝向、闪避状态必须在缩略图尺寸下清晰可辨。
- 角色与背景明度差至少 30%
- 角色永久像素描边（1px 深色轮廓）
- 地面纹理对比度不超过角色层的 50%

**设计测试**：任意常态截图在约 200px 宽缩略图下，0.2 秒内能定位到角色位置和朝向 → 合格。

#### C2. 释放的视觉独占权
*锚定支柱：压迫与释放 + 每一枪都要有感觉*

技能爆发的前 0.5 秒内，所有非核心视觉元素必须让步：
- 屏幕四角暗角加深至 60%
- 非目标敌人亮度临时降至 50%
- 背景层对比度临时降低
- 全场只有爆发粒子有资格"说话"

**设计测试**：如果普通射击的视觉效果在爆发瞬间依然抢眼 → 不合格。释放没有获得视觉独占权。

#### C3. 构筑的视觉方言
*锚定支柱：构筑决定命运*

每个构筑方向必须形成完整的视觉方言——四要素统一：
- 主色调
- 粒子形状族
- 弹道风格
- 命中特效颜色

**设计测试**：同一构筑方向的两个升级看起来像"同一套体系的不同等级"，而不是"两个不同游戏的技能"。方言的一致性 > 单个特效的华丽程度。

## Section 2: Mood & Atmosphere

### 情绪温度弧线

```
菜单(冷·静) → 常态战斗(中性·紧) → 极限闪避(冷·锐) → 技能爆发(热·爆) → 波次结束(中性·轻) → 死亡(暖·烬)
```

### 1. 菜单 / 准备

| 维度 | 设定 |
|------|------|
| **情绪目标** | 战前冷静期待——"暴风雨前的平静" |
| **色温** | 冷色主导（深蓝 #1a1a2e → 青灰方向） |
| **对比度** | 低对比，柔和 |
| **氛围词** | 冷静、聚焦、期待、工业感 |
| **能量** | 平稳 |
| **承载视觉元素** | 极淡的扫描线或网格背景，暗示"设施/基地" |

### 2. 常态战斗（压迫阶段）

| 维度 | 设定 |
|------|------|
| **情绪目标** | 紧绷的专注——"刀尖上的行走" |
| **色温** | 中性偏冷，根据场景可微调 |
| **对比度** | 中高（保证可读性，满足 C1 铁律） |
| **氛围词** | 紧绷、清晰、战术感、积蓄 |
| **能量** | 紧凑 |
| **承载视觉元素** | 暗角 20-30% 逐渐加深，屏幕边缘粒子开始聚集（压迫的视觉预兆） |

### 3. 极限闪避瞬间

| 维度 | 设定 |
|------|------|
| **情绪目标** | 冷锐的精准——"时间冻结中的一把刀" |
| **色温** | 瞬间偏蓝/冷色（冰蓝 #4af → 亮蓝 #8df 方向） |
| **对比度** | 极高对比 |
| **氛围词** | 冷锐、清晰、锋利、掌控 |
| **能量** | 瞬间停顿（时间缩放 0.2x） |
| **承载视觉元素** | 全屏临时冷色滤镜 + 角色残影轨迹 + 画面边缘锐化处理 |

### 4. 技能爆发（释放阶段）

| 维度 | 设定 |
|------|------|
| **情绪目标** | 宣泄的狂喜——"积压的一切此刻释放" |
| **色温** | 瞬间转暖/热色（构筑决定：火焰橙、雷电黄、异星紫） |
| **对比度** | 极端——暗角最深（60%），爆发核心最亮 |
| **氛围词** | 暴力、宣泄、炽热、释放、压倒性 |
| **能量** | 狂乱（持续 0.5-1 秒后快速回落） |
| **承载视觉元素** | 暗角猛增至 60% + 全屏粒子爆炸 + 非目标敌人亮度临时降至 50%（C2 视觉独占权） |

### 5. 波次结束 / 升级选择

| 维度 | 设定 |
|------|------|
| **情绪目标** | 轻快的喘息——"做决定，然后继续" |
| **色温** | 中性（回归默认，不加滤镜） |
| **对比度** | 低对比 |
| **氛围词** | 轻巧、明快、期待、选择 |
| **能量** | 平稳偏轻 |
| **承载视觉元素** | 暗角瞬间清零 + 画面快速恢复清晰 + 升级卡片带微光 |

### 6. 死亡 / 结算

| 维度 | 设定 |
|------|------|
| **情绪目标** | 温暖的余烬——"这一局结束了，但下一局已经在燃烧" |
| **色温** | 暖暮色（琥珀 #c87d3a → 锈色 #8b4513 方向） |
| **对比度** | 低对比，柔和 |
| **氛围词** | 温暖、反思、余韵、激励 |
| **能量** | 沉思 |
| **承载视觉元素** | 画面去饱和 30% + 暖色滤镜叠加 + 统计数字逐个浮现（余烬感） |

## Section 3: Shape Language

### 角色剪影哲学：体量层级制

*锚定支柱：闪避即武器（C1 常态可读性铁律）*

| 层级 | 体量 | 视觉特征 | 游戏角色 |
|------|------|---------|---------|
| **小型** | 16-24px 直径 | 圆形/blob，无突出特征，快速移动 | 虫群杂兵（大量，一枪一个） |
| **中型** | 32-48px | 类人形 + 武器突起（枪口、爪牙），中等移速 | 远程兵/精英 |
| **大型** | 64-96px | 块状重型轮廓，占据显著空间，慢速 | 重装/Boss |

**原则**：体量越大 → 移动越慢 → 威胁越高。玩家凭剪影大小在 0.1 秒内判断威胁等级。

**设计测试**：如果三种敌人的缩略图剪影被混在一起，能否凭轮廓一眼归类？不能 → 体量差异不够。

### 环境几何：工业基底 + 有机侵蚀

*锚定支柱：压迫与释放*

- **波次 1-3（纯工业基底）**：直角墙面、金属地板格、管道。硬边几何主导。干净、清晰。
- **波次 4-7（侵蚀开始）**：地板上出现弧形有机纹理（外星菌丝/血管脉络），但**不覆盖角色行走区域**。
- **波次 8+（深度侵蚀）**：墙面出现脉动有机组织，背景层出现不规则生物轮廓。

**硬约束**：有机侵蚀永远只作用于背景层和装饰层——角色行走面保持低对比工业网格。侵蚀是"氛围叙事"，不是"操作障碍"。

**设计测试**：任意有侵蚀的帧中，角色脚下的地面依然能清晰辨认 → 如果有机纹理"吞掉"了角色的脚 → 侵蚀跨过了背景/行走层的边界。

### UI 形状语法：混合 Diegetic

*锚定支柱：闪避即武器 + 构筑决定命运*

- **角色光环（脚下，diegetic）**：血量以光环段数显示——受击次数直接可视在角色周围
- **技能充能球（背后，diegetic）**：角色背后悬浮的高对比像素小球——充能进度 = 小球亮度/大小/旋转速度；满充能 = 小球剧烈发光 + 脉动
- **闪避充能指示（环绕角色，diegetic）**：环绕角色的小光点——亮着的点数 = 剩余闪避次数
- **升级卡片（HUD）**：波次结束时弹出独立卡片界面——粗像素边框 + 像素点阵文字
- **波次/冷却（最小 HUD）**：屏幕底部最简像素标注

**原则**：战斗中所有关键信息在角色身上或周围（不需要眼睛离开角色），暂停时（升级选择）才使用独立 HUD 界面。

**设计测试**：战斗中玩家能否在视线不离开角色的情况下知道血量、技能充能和闪避次数？如果必须看屏幕角落 → 信息位置不对。

### 主角形状 vs 支撑形状

| 角色 | 形状处理 | 对比度 |
|------|---------|--------|
| **英雄形状（角色）** | 本体 + 脚下光环 + 背后充能球 + 环绕光点。1px 深色描边。 | 画面最高 |
| **威胁形状（敌人）** | 块状深色轮廓，向角色方向移动。体量 = 威胁信号。 | 中高 |
| **释放形状（爆发）** | 圆形扩散、星光放射、线性冲击波——取决于构筑方向。0.5 秒独占 | 瞬间最高 |
| **背景形状（场景）** | 工业几何 + 有机曲线。退居最低对比度层。 | 最低 |

| 色名 | 色值参考 | 语义角色 | 使用场景 |
|------|---------|---------|---------|
| **工业灰蓝** | #3a4a5c | 中性·常态·背景 | 场景基底、地板、墙面 |

### 技能爆发双色结构

> 电光蓝冲击波外环 + 橙红毁灭核心 = "冷能量壳包裹热毁灭点"

| 层次 | 颜色 | 视觉表现 | 语义 |
|------|------|---------|------|
| **外壳** | 电光蓝 #2868f0 | 圆形扩散冲击波、粒子外环、屏幕边框闪蓝 | "能量场在膨胀" |
| **核心** | 橙红 #f04018 | 爆心亮点、中心放射光线、角色位置瞬间白热 | "毁灭就在这一点" |
| **残留** | 电光蓝 → 冷青淡出 | 爆发后粒子碎片飘散 | "余波" |

**设计测试**：爆发帧中，外壳和核心必须同时可见——如果电光蓝太亮吞掉了橙红核心 → 冲击力损失一半。如果橙红太大覆盖了电光蓝 → 失去"能量壳"的层次感。

### 语义色彩词汇表

| 信号 | 颜色 | 含义 | 出现位置 |
|------|------|------|---------|
| **玩家/安全** | 灰白+墨绿 | 你是人类幸存者，干净而专注 | 角色本体 |
| **能量/释放** | 电光蓝 #2868f0 | 技能就绪、能量外溢 | 充能球满状态、冲击波外环 |
| **爆发/毁灭** | 橙红 #f04018 | 技能的毁灭极点 | 爆发核心、暴击特效 |
| **精准/闪避** | 冷青 #4ac8e8 | 极限操作、时间操控 | 极限闪避瞬间、闪避光点 |
| **威胁/侵蚀** | 侵蚀紫红 #7a2a3c | 有机侵蚀扩散、敌群密集 | 屏幕边缘暗角、有机纹理 |
| **结构/秩序** | 深钢蓝 #1a2a3a | 工业设施的人类秩序 | 建筑结构、初始波次场景 |
| **中性/常态** | 工业灰蓝 #3a4a5c | 非战斗信息、背景 | 地面、普通墙面 |

### 色彩温度弧线

```
菜单(冷深蓝) → 常态(灰蓝) → 侵蚀渐深(暖紫红渗入边缘) → 极限闪避(冷青突闪) → 释放(电光蓝冲击波 + 橙红核心) → 波次结束(回归灰蓝) → 死亡(暖暮琥珀)
```

### UI 色板

**Diegetic 元素**（从世界色衍生）：
- 血量光环段：纯白灰（完整）→ 暗红（受损）→ 黑（耗尽）
- 技能充能球：灰蓝（空）→ 冷青（充能中）→ 电光蓝（满）→ 电光蓝+橙红脉动（可释放）
- 闪避充能点：冷青（可用）→ 灰蓝（冷却中）

**HUD 元素**（独立高对比）：
- 像素数字/文字：纯白
- 强调/信息：冷青
- 警告/满充能：电光蓝 → 橙红（最高级别）
- 升级卡片边框：纯白 1px 像素描边

### 色盲安全

| 风险色对 | 色盲类型 | 备份信号 |
|---------|---------|---------|
| 冷青 / 灰蓝（闪避可用 vs 冷却） | 蓝黄色盲 | 可用 = 亮+脉动 / 冷却 = 暗+静止 |
| 橙红 / 侵蚀紫红（爆发 vs 威胁） | 红绿色盲 | 爆发 = 电光蓝外壳 + 爆炸动画 + 音效 / 威胁 = 缓慢脉动 + 低音 |
| 电光蓝 / 冷青（释放 vs 闪避） | 蓝黄色盲 | 释放 = 大范围 + 冲击波 / 闪避 = 角色周围 + 时间缩放 |
| 墨绿 / 灰蓝（角色 vs 背景） | 红绿色盲 | 角色 = 1px 描边 + 脚下光环 + 背后充能球 |

**原则**：任何仅靠颜色传达的信息，必须有至少一个非颜色备份信号（形状、大小、动画、位置、音效）。

## Section 5: Character Design Direction

### 玩家角色视觉原型

| 维度 | 设定 |
|------|------|
| **比例** | 头:身 ≈ 1:4，均衡写实比例 |
| **45度俯角特征** | 银白头顶 = 天然位置信标（C1 铁律的核心载体），肩部+身体指向 = 朝向识别 |
| **站姿** | 微屈膝战术姿态，双脚分开，枪口向前下方 |
| **移动姿态** | 身体略前倾，枪维持水平，移动时脚部有明显交替 |
| **闪避姿态** | 身体侧倾 + 残影轨迹，方向性明确（向哪闪就向哪倾） |
| **尺寸** | 玩家 56-64px 高 |

### 敌人视觉区分

| 层级 | 尺寸 | 剪影特征 | 色相偏移 | 移动模式 |
|------|------|---------|---------|---------|
| **小型虫群** | 16-24px | 圆/blob、椭圆、带刺圆（3种变体） | 暗绿 → 灰绿 → 褐绿（≤30度偏移） | 直线冲/之字形/环绕 |
| **中型类人** | 32-48px | 枪口突起/爪牙突起/盾牌突起（3种变体） | 灰褐 → 暗红褐 → 紫褐 | 走射/冲锋/保持距离 |
| **大型块状** | 64-96px | 长方体/不规则块/多足巨兽（3种变体） | 深灰 → 深紫 → 深红 | 慢推/冲撞/召唤 |

**50+ 敌群约束**：小型敌人之间必须保持至少 1px 的背景间隙（碰撞半径强制分离 + 描边兜底）。

### 动画风格（高帧方向）

| 动作 | 帧数 | 说明 |
|------|------|------|
| **行走** | 6-8 帧 | 循环，带武器上下微浮动 |
| **射击** | 4-6 帧 | 枪口火光 + 后坐力位移 |
| **闪避** | 6-10 帧 | 方向性侧倾 + 残影拖尾 |
| **技能爆发** | 8-12 帧 | 蓄力（收拢）→ 释放（扩散） |

**关键帧优先原则**：每一帧必须传达明确的状态变化。高帧数表达更细腻的动作阶段。配合残影和粒子 VFX——帧动画给结构，VFX 给冲击力（支柱 2：每一枪都要有感觉）。

### LOD 哲学

| 角色类型 | 像素尺寸 | 最小可读特征 |
|---------|---------|------------|
| **玩家角色** | 56-64px | 2px（服饰细节、装备轮廓、银白头发 4-6px 亮区） |
| 中型敌人 | 32-48px | 1.5px（武器突起、身体方向） |
| 小型敌人 | 16-24px | 1px（剪影形状） |
| 大型敌人 | 64-96px | 3px（装甲板块、弱点标记） |

**银白头发位置信标**：玩家角色的银白头发在 45 度俯视角下天然位于画面最上方——在任何敌群密度和粒子密度下，灰白发顶都是第一个被识别的玩家信号。配合 1px 深色描边，形成"亮顶+暗边"的双重可读性保障。这是 C1 铁律（0.2 秒定位角色）的核心实现手段。

**"2px 可读性"规则**：角色身上的任何有意设计的视觉特征，必须至少占 2px 宽。1px 细节在运动中被像素采样吃掉。

## Section 6: Environment Design Language

### 建筑风格：废弃化工园区

**设定**：一座被外星生物入侵的废弃化工厂——反应釜、储罐区、管道走廊、废弃厂房。工业衰败 + 外星侵蚀的双重压迫。

**建筑元素**：
- 巨型储液罐（圆柱体障碍物，表面锈蚀）
- 管道网络（水平/垂直走向的管线束，形成天然掩体和通道边界）
- 反应釜车间（开阔空间 + 中央大型设备 = 竞技场式战斗区域）
- 控制室残骸（仪表盘、断裂的控制面板、闪烁的警报灯）
- 输送带和料斗（线性障碍物）

**情绪传达**：人类工业秩序已被废弃，化学品残留与外星生物产生未知反应——侵蚀不只是入侵，更是工业毒性与生物污染的叠加。

### 纹理哲学

| 层级 | 纹理处理 | 约束 |
|------|---------|------|
| **地板** | 混凝土灰基底 + 裂缝像素 + 化学品泄漏痕迹 | 对比度不超过角色层 50%（C1 铁律） |
| **墙面/设备** | 锈蚀金属（橙褐斑点像素）、剥落漆面、管道铆钉 | 不与敌人剪影重叠区域竞争 |
| **有机侵蚀** | 化工残留（黄绿毒液）+ 外星菌丝（紫红脉络）混合纹理，1-2px 宽 | 只在背景层和装饰层 |
| **化学泄漏** | 黄绿色水洼像素（地面装饰层，不阻碍移动） | 可作为环境危害的视觉预示 |
| **禁止** | 噪点纹理——在 45 度角下产生视觉泥浆 | 绝对禁止 |

### 场景物件密度：稀疏功能主义

- **必须有**：储罐/管道/反应釜（定义战斗空间形状的障碍物）
- **最好有**：可摧毁物件（锈蚀油桶——打爆产生范围伤害）、掩体设备（控制台残骸）
- **可以有**：废弃防护服、散落化学品容器、断裂输送带（不超过画面面积 10%）
- **不能有**：无理由杂物、与敌人剪影混淆的物件

### 环境叙事（无文字）

- 紧急疏散标志（被撕掉一半、或覆盖了外星菌丝）
- 化学品泄漏的拖痕（从破损阀门延伸到房间角落）
- 废弃防护服/防毒面具散落（暗示工人仓促撤离）
- 断裂管道中滴落的化学液滴（像素动画，2-3 帧循环）
- 控制面板闪烁的错误代码（无实际文字，只有乱码像素图案）
- 有序→混乱→侵蚀：完整设备→泄漏+裂缝→管道爆裂+有机组织覆盖

### 波次推进的三阶段视觉

| 阶段 | 波次 | 照明 | 环境粒子 | 场景状态 |
|------|------|------|---------|---------|
| **阶段 1** | 1-3 | 应急照明（冷白荧光，部分闪烁） | 无 | 完整但废弃的设备，化学品容器密封 |
| **阶段 2** | 4-7 | 灯光不稳定闪烁，部分区域昏暗 | 化学蒸汽粒子（黄绿）+ 孢子漂浮（边缘） | 管道开始破裂泄漏，储罐出现裂缝，第一批紫红菌丝出现在墙面 |
| **阶段 3** | 8+ | 生物荧光替代人工照明（紫红+黄绿混合），暗角 30% | 密集孢子 + 化学蒸汽 + 脉动有机轮廓 | 管道爆裂、储罐倾覆、有机组织覆盖 30% 背景、地板出现化学+生物混合水洼 |

## Section 7: UI/HUD Visual Direction

### 基础分辨率

游戏渲染分辨率：**960×540**（整数倍拉伸至 1080p/1440p/4K）

### Diegetic UI 元素

#### 血量光环（脚下）

- **形状**：圆形分段环，半径 ~20px，1px 宽像素圆弧，位于角色脚底地面层
- **分段逻辑**：每段 = 1 点血量。段间 1px 空隙。满血 = 完整圆环。
- **动画**：受击 → 受损段 3 帧白闪→暗红→黑，碎片粒子（2-3个 1-2px）向外飞出 6px 后消失。回血 → 恢复段 4 帧黑→暗红→白灰渐亮。

#### 技能充能球（背后）

- **尺寸**：12-14px 直径小球，悬浮在角色背后/上方 ~8px。1px 纯白描边 + 内部填充 + 外围光晕环。
- **状态**：
  - 空：灰蓝 #3a4a5c，光晕关闭，静止
  - 充能中：冷青 #4ac8e8，1px 光晕微微脉动
  - 满：电光蓝 #2868f0，2px 光晕剧烈脉动
  - 可释放：电光蓝 + 中央橙红核心亮点 #f04018（2px），外围光晕交替闪烁蓝/橙
- **动画**：充能进度变化 200ms 平滑插值。满充能瞬间球体短暂放大至 120%（4帧）→ 回弹至 100%（6帧）。

#### 闪避充能光点（环绕角色）

- **排列**：3-4 个光点均匀分布在 ~28px 半径圆形轨道上。光点随轨道缓慢旋转（~0.5转/秒）
- **单个光点**：3×3px 菱形像素点，1px 冷青填充 + 1px 白描边
- **状态**：
  - 可用：冷青 #4ac8e8，缓慢脉冲（明度 80%-100%，周期 ~1.5 秒）
  - 冷却中：灰蓝 #3a4a5c，静止，明度 40%
  - 消耗瞬间：白闪 2 帧 + 收缩消失 4 帧（3×3→1×1→无）
  - 恢复瞬间：1×1 出现 2 帧 + 弹出 4 帧 + 亮闪 2 帧 + 恢复脉冲

### 升级卡片

- **尺寸**：180×240px（960×540 基准）
- **边框**：2px 纯白 #ffffff 像素描边，四角外扩 2px（像素风"厚角"）。选中时切换电光蓝 #2868f0 + 1px 外发光
- **底色**：深钢蓝 #1a2a3a，85% 不透明度（透出模糊战场背景）
- **布局**：顶部 55% 图标区（64×64px 像素抽象符号，1px 冷青装饰框）+ 中部名称（12px 像素字体）+ 下部描述（8px 像素字体，最多2行）
- **排列**：水平居中，间距 24px，中间卡片上浮 8px（拱形排列）
- **动画**：屏幕暗角加深至 50% → 三卡依次从底部滑入（错开 60ms，总 0.6 秒）→ 呼吸光晕等待选择 → 选中后缩小飞入屏幕中心（0.3 秒）+ 暗角恢复（0.2 秒）

### 字体

- **主字体**：等宽像素点阵字体（参考 m3x6 / Pixeloid Mono），严格像素网格对齐，无抗锯齿
- **尺寸**：12px 粗体（标题/波次）+ 8px 常规（描述/冷却）+ 10px 粗体（伤害跳出数字）
- **语言**：MVP 阶段英文优先——中文在 8-12px 点阵下笔画过密，Tier 2 扩展 CJK 点阵字体

### 战斗中最小 HUD 布局

```
┌─────────────────────────────────────┐
│  WAVE 5                    x 47    │  顶部：波次(左)+击杀(右)，8px，50%不透明度
│                                     │
│         [角色 + Diegetic UI]         │  中央：所有关键战斗信息在角色身上
│                                     │
│  [武器]     [技能1冷却]  [技能2冷却]  │  底部：16px 图标+8px 文字，50%不透明度
└─────────────────────────────────────┘
```

- **不透明度策略**：常态 50%，信息变化时升至 85%（持续 0.5 秒后回落），释放瞬间（C2 视觉独占权）降至 20%

## Section 8: Asset Standards

### 基础分辨率

**960×540**，整数倍拉伸至 1080p/1440p/4K。240fps 在此分辨率下 GPU 负载极低。

### 文件格式与目录

- **格式**：PNG（8-bit indexed 或 32-bit RGBA）。禁止 JPEG/WebP。
- **目录结构**：

```
assets/sprites/
├── characters/   {player/, enemies/{small,medium,large}/, shared/}
├── environment/  {structures/, floors/, props/, erosion/}
├── vfx/          {particles/, impacts/, aoe/, screen/}
└── ui/           {diegetic/, hud/, cards/}
```

### 命名规范

格式：`[前缀]_[类别]_[名称]_[变体].[扩展名]`，全小写，下划线分隔。

| 类型 | 前缀 | 示例 |
|------|------|------|
| 玩家角色 | `chr_player` | `chr_player_idle_sheet.png` |
| 小/中/大敌人 | `enm_sml/mid/lrg` | `enm_med_gunner_attack_sheet.png` |
| 环境结构/地板/道具 | `env_str/flr/prp` | `env_prp_barrel_explosive.png` |
| VFX 粒子/命中/屏幕 | `vfx_ptc/hit/scr` | `vfx_ptc_shockwave_blue_sheet.png` |
| UI diegetic/HUD/卡片 | `ui_die/hud/crd` | `ui_hud_wave_number.png` |

### 精灵表规格

| 资产类型 | 最大精灵表 | 帧间 Padding | 布局 |
|---------|-----------|-------------|------|
| 玩家角色 (56-64px) | 2048×2048 | 2px | 水平条带（单方向）或网格（多方向） |
| 小型敌人 (16-24px) | 512×512 | 2px | 网格 |
| 中型敌人 (32-48px) | 1024×1024 | 2px | 网格 |
| 大型敌人 (64-96px) | 2048×2048 | 2px | 网格 |
| 环境 | 4096×4096 | 2px | 砖块排列 |
| VFX 粒子 | 512×512 | 1px | 网格图集 |
| UI | 1024×1024 | 2px | 集中一表 |

每个精灵表必须配套 `.json` 元数据文件（帧尺寸、帧数、布局方式、anchor 坐标、fps、方向列表）。

### Godot 4.6.2 导入设置

**项目级设置**：
- `Canvas Textures > Default Texture Filter`：**Nearest**
- `2D Snapping > Use GPU Pixel Snap`：**On**
- `Screen Space AA`：**Disabled**
- `Window > Stretch > Mode`：**canvas_items**
- `Viewport Width/Height`：**960 / 540**

**统一导入预设 `pixel-art-2d.tres`**：
- Texture Filter：**Nearest**（像素美术关键设置）
- Compress > Mode：**Lossless**（VRAM 压缩破坏像素精确颜色）
- Mipmaps：**Disabled**
- sRGB：**Enabled**

例外：地板 tile 纹理 `Repeat = Enabled`，全屏覆盖纹理 `Repeat = Disabled`。

### 粒子纹理预算

| 粒子类型 | 单帧最大 | 图集尺寸 | 帧数 |
|---------|---------|---------|------|
| 通用点粒子 | 8×8px | 64×64 | 64 |
| 冲击波粒子 | 16×16px | 128×128 | 64 |
| 爆发核心粒子 | 8×8px | 64×64 | 32 |
| 化学蒸汽/孢子 | 12×12px | 96×96 | 48 |
| 残影粒子 | 24×24px | 128×128 | 16 |

**每帧粒子预算**：常态战斗 ≤200，技能爆发峰值 ≤800，波次过渡 ≤50。
**总 vfx/ 纹理 VRAM**：< 2MB。

### 资产校验清单

每个资产提交前必须通过：
- PNG 格式，无嵌入色彩配置文件
- 命名符合规范
- 尺寸符合精灵表限制
- 帧间 padding ≥2px（粒子 ≥1px）
- 配套 `.json` 元数据完整
- 导入预设为 `pixel-art-2d.tres`
- 角色：1px 深色描边 + 银白头发为最亮区域
- 地板纹理：对比度 ≤ 角色层 50%（C1）
- 无噪点纹理
- 粒子图集帧中心对齐
- 总 vfx/ VRAM < 2MB

## Section 9: Reference Direction

### 游戏参考

#### 挺进地牢（Enter the Gungeon）

**提取什么**：
- 敌人子弹 vs 玩家子弹的色彩编码系统（敌人弹红/紫，玩家弹白/蓝）——直接应用于常态可读性
- 地板在缩略图下的低对比度处理：浅灰基底 + 细网格线，不抢夺角色注意力
- 45 度俯角下角色 1px 描边的执行标准——描边是深黑 #080808 而非纯黑，避免"纸片人"感

**规避什么**：
- 挺进地牢的色彩饱和度高、偏卡通化——我们需要工业灰蓝的低饱和基调
- 其 UI 是完全独立 HUD（屏幕四角分布信息）——我们用混合 Diegetic（角色身上信息）
- 其场景是 dungeon 迷宫式——我们的是开放化工园区，不做走廊式空间

#### 死亡细胞（Dead Cells）

**提取什么**：
- 像素受击反馈的"三层递进"：命中白帧（1-2帧）→ 屏幕微震 → 粒子碎片飞溅方向与攻击方向一致
- 高帧像素动画的关键帧密度感——帧多但每帧信息密度高，不靠模糊过渡
- 构筑方向通过武器/技能的颜色统一来传递——同一构筑的命中色、粒子色、残影色三合一

**规避什么**：
- 死亡细胞是横版近战——我们的俯角射击需要完全不同的空间感
- 其 3D 角色渲染成像素的风格——我们是纯 2D 像素，不做 3D→2D 烘焙
- 黑暗中世纪色调——我们保持冷工业色调，不做暖调城堡

#### 绝地潜兵 2（Helldivers 2）

**提取什么**：
- "常态战斗"与"轨道打击/战备"之间的视觉反差幅度——压迫时画面拥挤、混乱、信息过载，释放时画面"呼吸"（清晰+明亮+慢）。这个对比幅度是我们"压迫→释放"的黄金参考
- 范围打击的视觉"独占权"——战备释放时其他视觉元素退让，玩家视线被强制吸引到打击点
- 大场面中玩家角色的视觉锚定——通过 UI 标记和队友高亮确保角色不丢失

**规避什么**：
- 3A 级别的粒子数量和 3D 渲染——我们的像素粒子需要更精炼
- 其第三人称追尾视角——我们是固定 45 度俯角
- 多人合作的视觉策略——我们是纯单人

#### 绝区零（Zenless Zone Zero）

**提取什么**：
- 极限闪避的时间缩放视觉语言：冷色滤镜瞬间偏移（偏蓝）+ 画面边缘锐化 + 音效/视觉的毫秒级同步
- 闪避成功的"三重确认"：时间缩放（世界层）+ 角色残影（角色层）+ 特效爆发（VFX 层）——三重同步广播闪避成功
- 角色设计中的黑绿配色 + 灰白发色的视觉平衡——安比的黑绿服饰如何在复杂背景中通过明度对比保持可读性

**规避什么**：
- 3D cel-shading 风格——我们是 2D 像素
- 都市/街头美学——我们的是废弃工业+外星侵蚀
- 其近战为主的战斗反馈——我们的射击需要弹道、弹着点、远距离命中反馈

#### Alien Shooter 2

**提取什么**：
- 俯角视角下"被包围"的空间感受——敌人从四面八方逼近时，屏幕边缘的威胁密度变化如何制造方向性压迫
- 大规模敌群中个体敌人的视觉降级策略：远处/边缘敌人降低细节，近处/中央敌人保持清晰——2D 像素中的"深度 LOD"
- 敌潮密度与玩家焦虑的关系曲线——多少敌人同屏时开始感到压迫，多少时感到绝望

**规避什么**：
- 其过时的 UI 和低分辨率
- 其写实（2000年代）风格——我们需要像素艺术的抽象感
- 其站桩射击的被动感——我们的核心是闪避+移动

### 非游戏参考

#### 工业废墟摄影（Chernobyl / 废弃工厂）

**提取什么**：
- 锈蚀金属的色彩范围：橙褐 #8b5a2b → 暗红褐 #5a2a1a → 灰褐 #6b5a4a，建立"废弃工业"的标准色板区间
- 混凝土裂缝的视觉模式：裂缝不是"线"而是"锯齿状空隙"，宽度不均匀（1-3px），裂缝边缘有浅色破碎痕迹
- 化学品残留的视觉特征：黄绿色水洼边缘有白色盐结晶环（蒸发残留物），管道滴落处形成放射状溅射痕迹
- 被遗弃的工业设备的"沉默叙事"：破损的仪表盘、散落的防护装备、被推倒的储物柜——不需要文字就能讲述"这里发生了什么"

**规避什么**：
- 不要做灰色废墟——纯粹的灰太单调。保留锈色和化学色的色彩丰富度
- 不要做"恐怖游戏"式的黑暗——足够的应急照明让场景可读
