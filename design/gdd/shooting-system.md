# 射击系统

> **Status**: Approved
> **Author**: user + agents
> **Last Updated**: 2026-05-07
> **Implements Pillar**: 每一枪都要有感觉（P2）— 射击是反馈链的第一环

## Overview

射击系统是玩家在《裂隙反应》中的主要攻击手段——鼠标左键按住即持续射击，鼠标指向即为瞄准方向。采用即时命中（hitscan）：按下扳机的瞬间，一条不可见的射线从枪口射出，第一个被命中的敌人立即承受伤害。子弹无限——不需要拾取弹药、不需要换弹——让玩家专注于闪避和走位，而不是资源管理。每一次命中都通过像素粒子、音效和屏幕震动三重要素确认（支柱2：每一枪都要有感觉）。

## Player Fantasy

射击追求的幻想是"枪即是手指的延伸"。鼠标指向哪里，子弹就命中哪里——没有弹道飞行时间、没有抛物线、没有随机散布。它是对玩家瞄准的纯粹尊重。在 50+ 敌群中，一发子弹带走一个杂兵——那种"指哪打哪"的精准和效率，就是射击系统最核心的权力幻想。

## Detailed Design

### Core Rules

**瞄准方向**：鼠标光标位置（世界坐标）− 玩家位置 = 瞄准方向。每帧更新。

**射击触发**：按住鼠标左键时，按射速间隔自动连续射击。松开立即停止。

**即时命中（Hitscan）**：
- 射击帧：从玩家位置向瞄准方向发射射线
- 射线长度 = 武器射程
- 命中第一个碰撞体 → 造成伤害（伤害值由伤害系统 C5 确定）
- 未命中任何碰撞体 → 无效果（子弹飞向场景外）

**子弹视觉**：虽然是即时命中，但每发都产生一条极短的像素弹道线（亮色，1-2帧）从枪口延伸至命中点或最大射程，确保射击"可见"。

**无限子弹**：无弹夹、无弹药拾取、无换弹。按住 = 射击，松开 = 停止。

**射移分离**：射击不影响移动，移动不影响射击——两者完全独立。

### States and Transitions

| 状态 | 射击 | 触发 |
|------|:--:|------|
| **可射击** | ✅ | 正常移动中、技能释放中 |
| **锁定** | ❌ | 闪避动画中、死亡、暂停、波次过渡 |

### Interactions with Other Systems

| 系统 | 接口 |
|------|------|
| 输入系统（F1） | `shoot` 按下状态 + `aim` 方向 |
| 玩家移动（C1） | 射击不影响移动——独立 |
| 伤害系统（C5） | 命中事件 → 伤害值 + 命中点坐标 |
| 技能系统（C4） | skill_2 自动为下一次攻击附加效果（伤害×2 + 穿透 1 个目标）。穿透时射线在第一次命中后继续飞向第二个目标 |
| VFX（P1） | 弹道线 + 命中粒子 + 屏幕震动 |
| 音频（F3） | 射击音效 + 命中确认音 |

## Formulas

### 射速

`fire_interval = 1.0 / fire_rate`

| 变量 | 符号 | 类型 | 范围 | 说明 |
|------|------|------|------|------|
| 射速 | fire_rate | float | 4-12 | 每秒射击次数 |

**示例**：fire_rate=8 → fire_interval=125ms，即每 125ms 发射一发。

### 命中检测

`hit = raycast(origin=player_pos, direction=aim_dir, max_distance=weapon_range)`

| 变量 | 符号 | 类型 | 范围 | 说明 |
|------|------|------|------|------|
| 玩家位置 | player_pos | Vector2 | 场景内 | 射线起点 |
| 瞄准方向 | aim_dir | Vector2 | 单位向量 | 射线方向 |
| 武器射程 | weapon_range | float | 500-1000 | 像素，超过此距离的敌人不会被命中 |

## Edge Cases

- **射击键和闪避键同时按下**：闪避优先——射击该帧不触发。闪避结束后若仍按住射击键，自动恢复
- **瞄准方向在玩家身上**（鼠标刚好在角色中心）：不射击——需要有效瞄准方向
- **射速间隔内松开再按下**：重置间隔计时器——防止宏连点突破射速限制
- **敌人死后 1 帧内的残留碰撞体**：忽略已标记死亡的敌人——不鞭尸
- **同帧多个敌人在射线上**：命中最近者（第一个）。例外：skill_2 激活时，穿透第一个目标后继续命中第二个（最多 2 个）

## Dependencies

- **上游依赖**：输入系统 F1（`shoot`+`aim`）、玩家移动 C1（坐标）
- **下游依赖**：伤害系统 C5（命中事件）、VFX P1（弹道+粒子）、音频 F3（射击音效）
- **技能系统 C4**：skill_2 命中附加

## Tuning Knobs

| 参数 | 默认值 | 安全范围 | 说明 |
|------|-------|---------|------|
| 射速 | 8/s | 4-12 | 太高画面闪，太低不够爽 |
| 武器射程 | 800px | 500-1200 | 在 960×540 下约 1.5 倍屏幕宽度 |
| 弹道线显示时间 | 2帧 | 1-3帧 | 像素弹道线持续帧数 |

## Visual/Audio Requirements

- **弹道线**：亮色 1px 像素线（纯白或武器构筑色），枪口→命中点/射程终点，持续 2 帧
- **命中粒子**：命中敌人时在命中点产生像素火花（8×8 粒子碎片，方向与射击方向一致）
- **音效**：射击音（短促）+ 命中确认音（与射击音分层）

## Acceptance Criteria

- **GIVEN** 玩家按住鼠标左键，**WHEN** 角色正常状态，**THEN** 按射速间隔持续射击
- **GIVEN** 玩家松开鼠标左键，**WHEN** 射击中，**THEN** 射击立即停止
- **GIVEN** 玩家射击且瞄准方向上有敌人，**WHEN** 射线命中敌人碰撞体，**THEN** 该敌人受到伤害
- **GIVEN** 玩家射击且瞄准方向上无敌人，**WHEN** 射线未命中，**THEN** 无伤害事件，只有弹道线显示
- **GIVEN** 玩家按住射击时触发闪避，**WHEN** 闪避动画中，**THEN** 射击暂停，闪避结束后自动恢复
- **GIVEN** 射线同时命中多个敌人，**WHEN** 同帧多个碰撞体，**THEN** 只命中最近者

## Open Questions

- **射速是否受构筑影响**：是否有升级选项增加射速？MVP 不涉及，但 `fire_rate` 应可动态修改
- **是否有爆头/弱点机制**：命中不同部位是否有伤害倍率？MVP 不做——所有命中统一伤害
