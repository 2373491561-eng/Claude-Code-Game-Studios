# VFX/粒子特效

> **Status**: Approved
> **Author**: user + agents
> **Last Updated**: 2026-05-07
> **Implements Pillar**: 每一枪都要有感觉（P2）— VFX 是反馈三要素的视觉层；压迫与释放（P4）— 暗角和粒子是压迫的视觉预兆

## Overview

VFX/粒子特效系统是《裂隙反应》中"每一枪都要有感觉"的视觉兑现。从射击的弹道线、命中的像素火花、闪避的残影轨迹、技能爆发的电光蓝冲击波+橙红核心——每一个游戏事件都有对应的像素粒子反馈。它管理常态暗角（压迫的视觉预兆）、屏幕震动（触觉反馈）、时间缩放（极限闪避的视觉语言），以及波次过渡的暗角加深/恢复。所有粒子使用 GPU 模式 + 对象池，确保 50+ 敌人 + 800 粒子峰值下依然 240fps。

## Player Fantasy

VFX 追求的幻想是"每一帧都在说'打中了'"。射击 → 亮色弹道线 + 命中火花碎片。闪避 → 残影拖尾 + 时间冻结。技能爆发 → 全屏粒子爆炸 + 暗角加深至 60%。你不是在看一个游戏画面——你是在经历一场像素风暴。当释放的瞬间全场只有爆发粒子有资格"说话"，那一帧的视觉独占权就是你对战场的主宰宣言。

## Detailed Design

### Core Rules

**粒子池**：预分配粒子节点池，不动态创建/销毁。

| 粒子类型 | 池大小 | 图集规格 | 激活条件 |
|---------|:-----:|---------|---------|
| 弹道线 | 16 | 1×64px 白线，着色动态 | 每发子弹 |
| 命中火花 | 128 | 64×64，8×8 网格 | 子弹/技能命中 |
| 闪避残影 | 8 | 128×128，16 帧 | 闪避动画 |
| 爆发冲击波 | 64 | 128×128，8×8 网格 | 技能 1 释放 |
| 爆发核心 | 32 | 64×64，4×4 网格 | 技能 1 释放 |
| 死亡碎裂 | 64 | 64×64，8×8 网格 | 敌人死亡 |
| 环境孢子 | 128 | 96×96，8×6 网格 | 波次 4+ 背景粒子 |
| 化学蒸汽 | 64 | 96×96，8×6 网格 | 波次 4+ 环境 |

**每帧粒子预算**：

| 场景阶段 | 上限 | 说明 |
|---------|:---:|------|
| 常态战斗 | 200 | 弹道+命中+环境 |
| 技能爆发（0.5s） | 800 | 峰值允许短暂突破 |
| 波次过渡 | 50 | 极简 |
| 死亡冻结 | 100 | 余烬 |

**屏幕效果**：
- **暗角**：常态 20%，压迫积累期加深至 30%，释放瞬间加深至 60%
- **极限闪避滤镜**：冷色偏移（偏蓝）+ 画面边缘锐化
- **时间缩放**：极限闪避 `time_scale=0.2`，恢复 200ms 内插值回 1.0

**构筑方向粒子**：根据当前构筑方向切换粒子颜色和形状（C3 原则）。

## Formulas

### 粒子回收

`acquire(): if pool not empty → pop and activate, else → reuse oldest active`
`release(particle): deactivate, push to pool`

### 暗角插值

`vignette = lerp(current, target, delta × 3.0)` — 快速但不过渡

## Edge Cases

- **爆发时粒子池耗尽**：复用最老的活动粒子——距离爆发中心最远者先被回收
- **时间缩放时粒子动画速度**：粒子 AnimationPlayer 的 `speed_scale` 跟随 `Engine.time_scale`
- **连续两次爆发间隔 < 0.5s**（构筑可使 CD 极短）：第二次爆发时如果池子尚未恢复，使用减少的粒子数（降至 50%）

## Tuning Knobs

| 参数 | 默认值 | 范围 | 说明 |
|------|-------|------|------|
| 常态暗角 | 20% | 10-30% | 太深深色干扰可读性 |
| 爆发暗角 | 60% | 40-80% | 释放视觉独占权 |
| 粒子池总大小 | ~500 | 300-800 | 影响内存和峰值性能 |
| 爆发粒子峰值 | 800 | 400-1200 | |
| 时间缩放恢复时长 | 200ms | 100-300ms | |

## Acceptance Criteria

- **GIVEN** 玩家射击命中敌人，**WHEN** 命中帧，**THEN** 命中点出现像素火花（方向性碎片+白帧闪烁）
- **GIVEN** 玩家闪避，**WHEN** 闪避动画播放，**THEN** 残影轨迹显示（2-3 个半透明拖尾帧）
- **GIVEN** 玩家释放技能 1，**WHEN** 技能触发，**THEN** 电光蓝冲击波扩散+橙红核心爆炸+暗角加深至 60%
- **GIVEN** 技能爆发结束，**WHEN** 0.5s 后，**THEN** 暗角恢复至 20%
- **GIVEN** 极限闪避触发，**WHEN** 闪避成功，**THEN** 全屏冷色滤镜+时间缩放+边缘锐化
- **GIVEN** 50+ 敌人战斗 + 技能爆发，**WHEN** 粒子峰值 800，**THEN** 帧时间 ≤ 4.17ms
