# 摄像机系统

> **Status**: Approved
> **Author**: user + agents
> **Last Updated**: 2026-05-07
> **Implements Pillar**: 闪避即武器（P1）、每一枪都要有感觉（P2）— 屏幕震动反馈

## Overview

摄像机是玩家在《裂隙反应》中的眼睛——以 45 度俯视角跟随玩家，将角色始终保持在画面近似中央，并向瞄准方向略微偏移，为前方的威胁留出更多视野。鼠标滚轮可以调整摄像机高度——拉近看清角色细节，拉远获得更广的战术视野。它跟随但不抖动、偏移但不突兀、缩放但不卡顿。每一次受击、闪避和技能爆发，它仍以不同强度的震动将冲击传递到手中。在极限闪避的时间冻结中，摄像机跟随世界一起减速——然后随着技能爆发猛烈回弹。

## Player Fantasy

摄像机是玩家的"战术之眼"。它不会机械地锁定——当玩家向右侧瞄准时，摄像机微微右移，让右侧的敌人更早进入视野；当敌人从四面八方涌来，滚轮一滚，视野拉远，全局态势一目了然。玩家不需要思考摄像机的存在——它天然地知道该看哪里、该看多远。这种"它比我还懂我"的默契，就是摄像机系统最根本的幻想。

## Detailed Design

### Core Rules

**跟随模式**：摄像机平滑跟随玩家角色，玩家始终保持在画面约 40-50% 位置（近似中央）。跟随使用平滑插值（lerp），不跳变。

**瞄准偏移**：摄像机在玩家瞄准方向上附加偏移——偏移量为画面尺寸的 10-15%。鼠标指向右侧 → 摄像机右移，右侧敌人更早进入视野。偏移使用缓动（ease-out），不跳变。

**缩放**：鼠标滚轮调整摄像机高度，实现视野缩放。
- 默认高度：基准视野（约 2.5m 等效宽度）
- 缩小（滚轮向下）：摄像机升高 → 视野扩大 → 角色占屏变小（最远约 4m 等效宽度）
- 放大（滚轮向上）：摄像机降低 → 视野缩小 → 角色占屏变大（最近约 1.5m 等效宽度）
- 缩放有上下限，使用平滑插值（speed: ~0.2s 完成过渡）

**屏幕震动**：不同事件触发不同强度的屏幕震动，通过摄像机 offset 快速偏移实现：

| 事件 | 强度 | 持续时间 | 衰减方式 |
|------|:---:|---------|---------|
| 普通受击 | 低 | 100ms | 线性衰减 |
| 极限闪避成功 | 中低 | 150ms | 先强后弱（ease-out） |
| 技能爆发 | 高 | 300ms | 先强后弱，伴随时间缩放回弹 |
| 大型敌人出现 | 中 | 200ms | 缓入缓出 |
| 死亡 | 重 | 500ms | 初始猛烈 → 逐渐平息 |

**时间缩放跟随**：极限闪避触发 `Engine.time_scale = 0.2` 时，摄像机跟随和偏移按时间比例减速（视觉上的"世界凝固"效果）。摄像机震动使用真实时间（`Tween.set_ignore_time_scale(true)`）——不受时间缩放影响。这与技能系统 GDD v3 对齐：震动始终以真实时间衰减，不会在时间缩放期间被拉伸。

### States and Transitions

| 状态 | 触发 | 说明 |
|------|------|------|
| **跟随** | 常态 | 平滑跟随玩家 + 瞄准偏移 |
| **缩放中** | 滚轮输入 | 高度平滑过渡到目标值 |
| **震动中** | 事件触发 | offset 快速偏移+衰减，震动期间不影响跟随逻辑 |

### Interactions with Other Systems

| 目标系统 | 数据流向 | 接口 |
|---------|---------|------|
| 玩家移动（C1） | 移动 → 摄像机 | 玩家世界坐标（跟随目标） |
| 射击系统（C2） | 瞄准 → 摄像机 | 瞄准方向 Vector2（偏移方向） |
| 闪避系统（C3） | 闪避 → 摄像机 | 极限闪避信号 → 震动 + 时间缩放 |
| 技能系统（C4） | 技能 → 摄像机 | 技能爆发信号 → 高强度震动 |
| VFX（P1） | 摄像机 → VFX | 摄像机参数（震动的 offset 值供粒子系统参考） |

## Formulas

### 瞄准偏移

`offset_aim = aim_direction × max_offset × smoothness`

| 变量 | 符号 | 类型 | 范围 | 说明 |
|------|------|------|------|------|
| 瞄准方向 | aim_dir | Vector2 | 任意方向 | 鼠标位置相对于玩家的方向 |
| 最大偏移量 | max_offset | float | 50-100px | 画面尺寸的 10-15%（960×540下约 80px） |
| 平滑系数 | smoothness | float | 0-1 | 0=无偏移，1=即时偏移。默认 0.3 |

**输出**：Vector2，摄像机位置 = 玩家坐标 + offset_aim

### 缩放

`zoom_level = clamp(current_zoom + scroll_delta × zoom_speed, zoom_min, zoom_max)`

| 变量 | 符号 | 类型 | 范围 | 说明 |
|------|------|------|------|------|
| 当前缩放 | current_zoom | float | zoom_min~zoom_max | 当前高度值 |
| 滚轮增量 | scroll_delta | int | -1, 0, 1 | 每帧滚轮变化 |
| 缩放速度 | zoom_speed | float | 0.05-0.2 | 每格滚轮的缩放量 |
| 最小缩放 | zoom_min | float | 1.0 | 最近（1.5m视野） |
| 最大缩放 | zoom_max | float | 3.0 | 最远（4m视野） |

### 震动衰减

`shake_offset = direction × intensity × decay(t)`

decay(t)：线性 `1 - t/duration` 或 ease-out `(1 - t/duration)²`

## Edge Cases

- **缩放期间触发震动**：震动叠加在缩放偏移之上——两者独立计算，不互相干扰
- **玩家在场景边缘**：摄像机不跟随超出场景边界——clamp 到场景边界内
- **瞄准偏移在边缘时**：如果偏移会让摄像机超出场景，偏移量自动缩减到安全值
- **时间缩放时滚轮缩放**：时间缩放不影响缩放速度——滚轮响应保持实时
- **同时多个震动触发**：取强度最高者，不叠加（避免 offset 过大导致画面脱离）

## Dependencies

- **上游依赖**：玩家移动 C1（坐标）、射击系统 C2（瞄准方向）、闪避系统 C3（震动信号）、技能系统 C4（震动信号）
- **下游依赖**：VFX P1（震动参数）
- **所有依赖目前均无 GDD**——需求已通过接口定义，具体实现等待对应 GDD

## Tuning Knobs

| 参数 | 默认值 | 安全范围 | 说明 |
|------|-------|---------|------|
| 瞄准偏移最大量 | 80px | 50-120px | 偏移过大画面晃动，过小没效果 |
| 跟随平滑速度 | 0.15 | 0.05-0.3 | 太低画面拖滞，太高画面跳 |
| 默认缩放级别 | 2.0 | 1.0-3.0 | 基准视野（对应2.5m等效宽度） |
| 缩放过渡速度 | 0.2s | 0.1-0.5s | 缩放过渡动画时长 |
| 震动强度（低/中/高） | 2/4/8px | 1-3/3-6/6-12px | 像素值，对应受击/闪避/爆发 |

## Visual/Audio Requirements

摄像机系统的视觉反馈体现在屏幕震动和缩放过渡上：

- **震动视觉**：摄像机 offset 快速偏移+衰减，震动方向与事件方向一致（如受击方向、爆发中心方向）
- **缩放过渡**：平滑插值缩放，不跳变。缩放动画使用 ease-in-out
- **时间缩放**：极限闪避时震动和缩放过渡跟随 `Engine.time_scale` 同步减速

## UI Requirements

摄像机系统不拥有 UI。缩放级别不在 HUD 上显示——玩家凭直觉感知视野范围。

## Acceptance Criteria

- **GIVEN** 玩家在场景中移动，**WHEN** 玩家坐标改变，**THEN** 摄像机平滑跟随，玩家始终在画面中央 40-50% 区域
- **GIVEN** 玩家向右瞄准，**WHEN** 鼠标在角色右侧，**THEN** 摄像机向右偏移，右侧视野增大
- **GIVEN** 玩家滚动鼠标滚轮向上，**WHEN** 滚轮输入，**THEN** 摄像机高度降低、视野缩小（放大）
- **GIVEN** 玩家滚动鼠标滚轮向下，**WHEN** 滚轮输入，**THEN** 摄像机高度升高、视野扩大（缩小）
- **GIVEN** 玩家触发极限闪避，**WHEN** 闪避成功，**THEN** 时间缩放 0.2x + 中低强度震动 150ms
- **GIVEN** 玩家释放技能爆发，**WHEN** 技能触发，**THEN** 高强度震动 300ms + 时间回弹
- **GIVEN** 玩家在场景边缘，**WHEN** 摄像机偏移即将超出场景，**THEN** 偏移自动 clamp 到场景边界内

## Open Questions

- **缩放上下限**：默认 1.0（近）到 3.0（远），最佳值需要 playtest 确定——太近看不见周围敌人，太远角色太小
- **瞄准偏移不对称性**：是否需要 x 轴偏移 > y 轴偏移？（水平视野通常比垂直更关键）MVP 先用对称偏移
- **震动方向**：是否需要始终垂直于事件方向，还是随机方向？MVP 先用随机方向，更容易实现
