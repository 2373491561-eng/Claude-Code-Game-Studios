# 技能系统

> **Status**: Approved
> **Author**: user + agents
> **Last Updated**: 2026-05-08 (design-review v3 — 5 blockers resolved, auto-attach revert, formula fixes, visual threshold correction)
> **Implements Pillar**: 压迫与释放（P4）— 技能爆发是"释放"的瞬间；构筑决定命运（P3）— 技能是构筑的核心载体

## Overview

技能系统管理两个技能，共同组成「压迫→释放」循环中"释放"的瞬间。技能 1（电光蓝冲击波 + 橙红核心）是时间冷却型，空格键触发——大范围清场，将积压的紧张感一次性释放。冷却速度与闪避充能挂钩（充能越多冷却越快——充能即「蓄」），闪避成功缩短冷却。取消闪避可退还 75% CD，避免惩罚性机制。技能 2 由极限闪避（充能≥1）激活 500ms 窗口——该窗口内下一次攻击自动附加 skill_2 效果（伤害×2 + 穿透1）。闪避成功即是资格，无需额外按键操作。释放瞬间：屏幕暗角加深、电光蓝冲击波扩散、橙红核心炸裂、BGM 闪避让位。

## Player Fantasy

技能追求的幻想是"积蓄后的爆发"。你忍了 15 秒——在敌群中闪避、射击、积累充能。技能槽满了——背后的充能球从电光蓝转为橙红脉动。你按下空格——冲击波扩散、全屏粒子爆炸、非目标敌人暗淡下去。那一刻，全场只有你有资格"说话"。技能不是"一个厉害的攻击"——它是"我憋了这么久，现在轮到我了"。

## Detailed Design

### Core Rules

**技能 1**（手动触发型）：
- 触发键：空格键
- 类型：时间冷却（默认 CD：15 秒真实时间，使用 `Time.get_ticks_msec()` 计时，不受 `Engine.time_scale` 影响）
- 效果：圆形冲击波（半径 200px）——电光蓝外壳 + 橙红核心爆发，清场伤害。基础伤害 = 1（一枪秒小型虫群，中型敌人扣 1/3 HP），构筑系统可提升
- **充能加速冷却**：冷却速度与当前闪避充能数挂钩——`cd_speed_multiplier = 1.0 + max(charge_count - 1, 0) × 0.5`。充能=3 时冷却以 2 倍速计时（15s → 等效 7.5s），充能=2 时 1.5 倍，充能=1 时 1.0 倍（正常速度）。充能=0 时 `cd_speed = 1.0`（正常速度，无加速无惩罚）
- 闪避缩短 CD（充能门控）：普通闪避（充能≥1）-3s；极限闪避（充能≥1）-8s；极限闪避（充能=0）不缩短 CD
- **CD 缩减上限**：单次冷却周期内累计缩减不超过基础 CD 的 60%（15s × 0.6 = 9s 上限）——防止连续三次极限闪避直接清空冷却
- 释放期间可移动（全速，不降低移动速度）
- 释放期间可闪避取消——取消后退还 75% CD（四舍五入到 0.1s）。例如技能刚释放（CD 重置至 15s），立即取消退还可将 CD 恢复至约 3.8s。取消退还不受 CD 缩减上限约束
- 释放动画 0.5s：前 0.2s 为启动阶段（可取消），后 0.3s 为活跃+恢复阶段（不可取消）

**技能 2**（自动附加型）：
- 触发条件：极限闪避成功且充能≥1（充能=0 时极限闪避不触发 skill_2 窗口）
- 触发窗口：极限闪避后 500ms 真实时间内（使用 `Time.get_ticks_msec()` 计时）
- 触发方式：窗口内下一次攻击自动附加 skill_2 效果——伤害×2 + 穿透 1。闪避成功即是资格，玩家无需额外按键
- 效果：下一次攻击强化为 skill_2 版本——基础效果 = 子弹伤害 ×2 + 穿透 1 个目标（最多命中 2 个敌人）。构筑系统可在此基础上进一步修改（额外穿透层数、范围溅射、元素附魔等）
- 窗口过期（500ms 内未执行攻击）→ 本次 skill_2 机会丢失，不累积
- 窗口内第二次极限闪避：skill_2 窗口重置——从第二次极限闪避重新计时 500ms（玩家已消费 skill_2 后获得新的，或覆盖未消费的窗口）
- 未消费 skill_2 时再次极限闪避：窗口刷新（重新开始 500ms 计时），不叠加（始终只有 1 层 skill_2 待消费）

**技能充能指示**：角色背后悬浮的充能球（12-14px 直径，`z_index = -1` 渲染在角色之后）——通过以下阈值映射冷却进度：

| 状态 | 冷却剩余比例 | 视觉效果 |
|------|:---------:|------|
| **空** | > 80% | 灰蓝，静态，不发光 |
| **充能中** | 30%-80% | 冷青，微光，缓慢脉动（1 Hz） |
| **即将就绪** | 0%-30% | 电光蓝，亮光，快速脉动（3 Hz） |
| **就绪** | = 0% | 电光蓝 + 橙红脉动（交替色相），强光，高频脉动（5 Hz）——可释放 |

冷却剩余比例 = `cooldown_remaining / base_cooldown`。冷却归零（ratio = 0）时技能才可释放——充能球视觉和功能状态完全一致。

### States and Transitions

| 状态 | 说明 |
|------|------|
| **冷却中** | 技能 1 不可用，充能球按阈值渐变（灰蓝→冷青→电光蓝） |
| **就绪** | 技能 1 可释放，充能球电光蓝 + 橙红脉动 |
| **释放中** | 技能 1 动画播放（0.5s：前 0.2s 可取消，后 0.3s 不可取消），可全速移动 |
| **取消恢复中** | 取消后退还 75% CD，从退还值继续冷却 |
| **skill_2 待机** | 极限闪避（充能≥1）后 500ms 窗口，下一次攻击自动附加 skill_2 效果 |
| **skill_2 释放中** | 蓄力攻击播放，窗口消费后关闭 |

### Interactions with Other Systems

| 系统 | 接口 |
|------|------|

| 闪避系统（C3） | 读取 `get_charge_count()` 计算 CD 加速；极限闪避（充能≥1）→ skill_2 窗口打开 + CD -8s；普通闪避 → CD -3s；极限闪避（充能=0）→ 无 CD 缩减、无 skill_2 窗口 |

## Formulas

### 技能 1 冷却（真实时间计时）

```
# 每帧冷却更新（使用真实时间，不受 time_scale 影响）：
elapsed = Time.get_ticks_msec() - last_cooldown_tick_ms
cd_speed_multiplier = 1.0 + max(get_charge_count() - 1, 0) × 0.5  # charge≥1 时加速，charge=0 时保持 1.0（无加速无惩罚）
cooldown_remaining -= (elapsed / 1000.0) × cd_speed_multiplier
cooldown_remaining = max(cooldown_remaining, 0)
last_cooldown_tick_ms = Time.get_ticks_msec()
```

> ⚠️ 冷却必须使用 `Time.get_ticks_msec()` 而非 `delta`——`Engine.time_scale = 0.2` 期间 `delta` 被缩放至 ~3.3ms，导致冷却以 1/5 速度计时（15s CD → 75s 真实时间）。`Time.get_ticks_msec()` 不受缩放影响。

充能加速效果：
- charge=3: `cd_speed = 2.0` → 15s 等效 7.5s
- charge=2: `cd_speed = 1.5` → 15s 等效 10s
- charge=1: `cd_speed = 1.0` → 15s 正常速度
- charge=0: `cd_speed = 1.0` → 15s 正常速度（无加速，无惩罚）

### 闪避 CD 缩减（充能门控）

- 普通闪避成功（充能≥1）：`cooldown_remaining -= 3.0s`
- 极限闪避成功（充能≥1）：`cooldown_remaining -= 8.0s`
- 极限闪避成功（充能=0）：不缩短 CD
- CD 缩减上限：单次冷却周期内累计缩减 ≤ `base_cooldown × 0.6` = 9s（防止连续三次极限闪避清空冷却）
- CD ≤ 0 时就绪——不额外预载至下一次冷却

### 取消退还

```
if cancel_during_startup:  # 前 0.2s 启动阶段
    refund = round(cooldown_remaining × 0.75 × 10) / 10  # 四舍五入到 0.1s
    cooldown_remaining = max(cooldown_remaining - refund, 0)
    # 退还不计入 CD 缩减上限（取消退还是恢复，非额外缩减）
```

- 例：技能刚释放（CD 重置至 15s），取消时 CD 剩余 14.7s → 退还 11.0s（14.7 × 0.75 四舍五入）→ CD 恢复至 3.7s
- 取消仅在启动阶段可用（释放后 0-200ms）——后 300ms 不可取消

### 充能球视觉阈值

| 冷却剩余比例 | 视觉 |
|:---:|------|
| > 80% | 灰蓝 |
| 30%–80% | 冷青，1 Hz 脉动 |
| 0%–30% | 电光蓝，3 Hz 脉动（即将就绪） |
| = 0% | 电光蓝+橙红交替，5 Hz 脉动（就绪——可释放） |

`cooldown_ratio = cooldown_remaining / base_cooldown`

### 技能 1 伤害

`damage = base_skill_damage × build_multiplier`

`base_skill_damage = 1`（一枪秒小型虫群 HP=1，中型敌人扣 1/3 HP（HP=3））

AoE 形状：圆形，半径 200px（以玩家为中心）。伤害应用：`PhysicsDirectSpaceState2D.intersect_shape()` 瞬时查询范围内所有敌人。

### skill_2 窗口（自动附加，真实时间计时）

```
skill_2_window_open = (charge >= 1) AND (time_since_perfect_dodge_ms < 500)
```

- 计时使用 `Time.get_ticks_msec()`（不受 time_scale 影响）
- 窗口内下一次攻击自动附加 skill_2 效果——无需额外按键
- 窗口内第二次极限闪避 → 窗口刷新（重新计时 500ms），不叠加
- 已有 skill_2 效果待消费时再次极限闪避 → 覆盖旧效果，窗口刷新（重新开始 500ms 计时），不叠加（始终只有 1 层待消费）
- 窗口过期未消费 → 机会丢失，后续攻击为普通攻击

### skill_2 基础效果

```
skill_2_damage = bullet_damage × 2
skill_2_pierce = 1  # 穿透 1 个目标，最多命中 2 人
```

- 窗口内下一次攻击自动附加效果——无需额外按键
- 构筑系统在此基础上叠加修改（额外穿透、范围溅射、元素附魔等）
- 基础值确保 skill_2 即使在没有构筑修改的情况下也有可测量的效果

## Edge Cases

- **技能 1 释放期间触发极限闪避（启动阶段前 0.2s）**：闪避取消技能——退还 75% CD，技能动画中断，粒子淡出（非杀死），进入冷却恢复状态
- **技能 1 释放期间触发极限闪避（后 0.3s 不可取消阶段）**：闪避不取消技能——技能动画和闪避动画同时播放。技能效果完整触发
- **CD 已就绪时闪避**：不额外减少 CD——CD 已为 0，缩减被浪费
- **极限闪避（充能=0）后 500ms 内攻击**：skill_2 不触发——窗口仅在充能≥1 的极限闪避后打开
- **技能 1 冷却中（充能=0）极限闪避成功**：不缩短 CD（闪避 GDD v2 门控），但玩家仍获得无敌帧
- **skill_2 窗口内第二次极限闪避（充能≥1）**：窗口刷新——重新开始 500ms 计时。已有 skill_2 效果待消费时，新窗口覆盖旧效果（不叠加 2 层）
- **skill_2 窗口内下一次攻击**：自动附加 skill_2 效果——伤害×2 + 穿透 1。消费窗口
- **skill_2 窗口过期后攻击**：普通攻击——无强化。机会丢失，需等待下一次极限闪避（充能≥1）
- **技能 1 释放帧与闪避触发帧重合（同帧）**：取消优先——闪避取消技能 1，退还 75% CD。技能效果不触发。此规则覆盖释放帧的启动阶段（t=0 属于 0-200ms 可取消区间）
- **技能 1 冷却中按下空格**：无反应——不消耗、不触发。充能球短暂闪烁红色（100ms）作为"不可用"反馈
- **累积 CD 缩减触及 9s 上限**：后续闪避的 CD 缩减被忽略——充能球闪烁金色（100ms）提示已达上限
- **取消退还后 CD 恢复至 ≤ 0**：技能立即就绪——取消退还后若 CD ≤ 0，技能变为可用状态
- **时间缩放期间技能 1 冷却**：冷却以真实时间继续计时（`Time.get_ticks_msec()`），不受 time_scale=0.2 影响。极限闪避的时间缩放不冻结技能冷却

## Dependencies

- **上游依赖**：输入系统 F1（`skill_1` 信号）、闪避系统 C3（`get_charge_count()` → CD 加速 + 充能门控 + skill_2 窗口 + CD 缩减）、射击系统 C2（skill_2 自动附加）
- **下游依赖**：VFX P1（爆发粒子——圆形冲击波 200px 半径）、音频 F3（阈值音效 + 爆发音效 + Ducking + skill_2 增强射击音效）、摄像机 F4（震动）
- **所有上游依赖已有 GDD。闪避系统已 Approved（v2）——技能 GDD 必须与其充能门控保持一致**
- **循环依赖 C4 ↔ C3**：闪避触发 skill_2 窗口 + CD 缩减（C4 消费 C3），技能 1 取消闪避 (C4 被 C3 中断)。通过退还 75% CD 解决——取消非惩罚性
- **实现注意**：技能 1 触发和闪避处理必须统一在 `_physics_process` 中通过 `Input.is_action_just_pressed()` 处理——不可分散在 `_input()` 和 `_physics_process()` 之间。同帧取消优先规则（见 AC7）依赖此架构

## Acceptance Criteria

### 核心释放

- **AC1a**：**GIVEN** 技能 1 就绪，**WHEN** 玩家按空格，**THEN** 以玩家为中心释放圆形冲击波（半径 200±10px），范围内所有敌人受到 1 点伤害（小型虫群 HP=1 → 死亡）。验证：调试模式下显示碰撞形状。
- **AC1b**：**GIVEN** 技能 1 刚释放（CD 重置至 15s），**WHEN** 前 200ms 内玩家按 Shift 闪避，**THEN** 技能被取消，CD 退还 75%（15s → CD 恢复至 3.8±0.5s），粒子淡出，充能球从"释放中"切换至相应冷却状态。
- **AC1c**：**GIVEN** 技能 1 释放中已过 200ms（不可取消阶段），**WHEN** 玩家按 Shift，**THEN** 闪避和技能动画同时播放，技能效果完整触发，不退还 CD。

### 充能加速冷却

- **AC2a**：**GIVEN** 技能 1 冷却剩余 10s，闪避充能=3，**WHEN** 计时 3s 真实时间，**THEN** 冷却剩余 ≤ 4±0.3s（cd_speed=2.0，3s × 2.0 = 6s 冷却恢复）。
- **AC2b**：**GIVEN** 技能 1 冷却剩余 10s，闪避充能=1，**WHEN** 计时 3s 真实时间，**THEN** 冷却剩余 = 7±0.3s（cd_speed=1.0，3s × 1.0 = 3s 冷却恢复）。
- **AC2c**：**GIVEN** 技能 1 冷却就绪，闪避充能=3，**WHEN** 释放技能 1 → 冷却重置为 15s → 充能下降至 2，**THEN** CD 加速倍率立即从 2.0 降至 1.5——冷却速度随充能实时更新。

### 闪避 CD 缩减（充能门控）

- **AC3a**：**GIVEN** 技能 1 冷却剩余 10s，充能≥1，**WHEN** 普通闪避成功，**THEN** 冷却剩余 7±0.5s。
- **AC3b**：**GIVEN** 技能 1 冷却剩余 10s，充能≥1，**WHEN** 极限闪避成功，**THEN** 冷却剩余 2±0.5s。
- **AC3c**：**GIVEN** 技能 1 冷却剩余 10s，充能=0，**WHEN** 极限闪避成功（仅无敌帧），**THEN** 冷却保持 10±0.5s——不缩短。
- **AC3d**：**GIVEN** 技能 1 当前冷却周期已累计缩减 9s（上限），充能≥1，**WHEN** 再次极限闪避，**THEN** CD 不再缩减，充能球短暂闪烁金色（100ms）。

### Skill_2 自动附加

- **AC4a**：**GIVEN** 极限闪避成功且充能≥1，**WHEN** 闪避后 500ms 内执行下一次攻击，**THEN** 该次攻击伤害为普通攻击的 2±0.1 倍，且子弹穿透 1 个目标（命中第一个敌人后继续飞向第二个）。

### 冷却时间域与反馈
