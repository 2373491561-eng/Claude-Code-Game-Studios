# 敌人系统

> **Status**: Approved
> **Author**: user + agents
> **Last Updated**: 2026-05-08 (design-review revision — state machines, telegraphs, pathfinding, performance architecture)
> **Implements Pillar**: 压迫与释放（P4）— 敌群密度 = 压迫感的来源

## Overview

敌人系统定义了《裂隙反应》中所有敌对实体的类型、行为和生命周期。三种体量层级——小型虫群（16-24px，HP=1）、中型类人（32-48px，HP=3）、大型块状（64-96px，HP=8）——通过体量差异让玩家在 0.1 秒内判断威胁等级。50+ 敌人同屏时，集中式敌人管理器批量更新 AI、MultiMesh 批量渲染，确保 240fps 帧预算不受影响。敌人由波次管理器调度生成——从第 1 波的零星虫群到第 10+ 波的三层混编，敌人密度就是"压迫"的物理化身。

## Player Fantasy

敌人追求的幻想是"它们无穷无尽，但我越来越强"。小型虫群被一枪一个——它们是让你感受到火力效率的"炮灰"。中型类人在远处瞄准——它们是让你练习闪避时机的"老师"。大型块状缓慢推进——它是检验你构筑成果的"考卷"。当屏幕上挤满三层敌人，你闪避、充能、爆发——那一瞬间，你碾压的不是数值，是你之前所有技能和构筑选择的积累。

## Detailed Design

### Core Rules

**敌人类型**：

| 属性 | 小型虫群 | 中型类人 | 大型块状 |
|------|---------|---------|---------|
| 尺寸 | 16-24px | 32-48px | 64-96px |
| HP | 1 | 3 | 8 |
| 移速 | 快（~200px/s） | 中（~120px/s） | 慢（~60px/s） |
| 伤害 | 1 | 1 | 2 |
| 行为 | 直线冲向玩家 | 保持距离 + 远程射击 | 缓慢推进 + 近战范围攻击 |
| 碰撞半径 | 8-12px | 16-24px | 32-48px |
| 同屏上限 | ~40 | ~10 | ~3 |

**敌人 AI**：每种类型独立的状态机，所有时间参数使用真实时间（`Time.get_ticks_msec()`，不受 `Engine.time_scale` 影响）。

**小型虫群**：
- **追逐** → 直线冲向玩家（200px/s）。若路径上有障碍物，采样流场方向（见"避障与寻路"节）。与玩家碰撞半径重叠时 → 接触伤害 1 点 → 进入 **受击冷却** 状态
- **受击冷却**：接触伤害后 200ms 内不再次造成伤害。期间向后推开 10-15px，然后返回追逐
- **受伤**：HP 减少时白帧闪烁 2 帧（~8ms at 240fps）→ 继续当前状态
- **死亡**：HP ≤ 0 → 立即禁用碰撞和 AI → 播放碎裂粒子（~200ms）→ 标记待移除。碰撞体移除延后（5-10 个/帧，见性能约束）

**中型类人**：
- **距离保持**：与玩家保持 150-200px 距离。使用滞后区间——进入 140px 内 → 撤退；超出 210px → 靠近；140-210px 之间 → 维持当前位置。撤退速度 180px/s，靠近速度 120px/s。撤退期间不可射击
- **攻击**：距离在 150-200px 且攻击冷却就绪时（冷却 1.5-2.0s，可调）→ 250ms 前摇动画（枪口蓄能闪烁）→ 发射子弹（150px/s，可见像素弹道纹理）。子弹最大飞行距离 600px（超出后销毁）。攻击期间敌人暂停移动
- **墙角行为**：若撤退被障碍物或场景边缘阻挡 >0.3s → 进入"速射"模式：连射 3 发（间隔 150ms），然后尝试横向平移绕过障碍物
- **受伤**：HP > 0 时受击 → 50ms 硬直（暂停移动和攻击）+ 白帧闪烁 2 帧 → 恢复当前状态
- **死亡**：HP ≤ 0 → 立即禁用碰撞和 AI → 播放爆炸粒子（~400ms）→ 标记待移除

**大型块状**：
- **缓慢推进**：以 60px/s 向玩家移动。每 5-8s（可调）触发一次**冲锋**
- **冲锋**：500ms 前摇（身体膨胀 + 地面裂纹粒子）→ 250px/s 冲刺 1s。冲刺方向锁定（前摇结束时玩家位置方向），冲刺期间不可转向。冷却 5-8s。冲锋可被闪避躲开（300ms 闪避 > 250px/s × 0.3s = 75px 位移容差）
- **近战攻击**：距离 < 80px 时触发。400ms 前摇（手臂抬起/身体发光）→ 造成 2 点伤害。冷却 2-3s。前摇期间暂停移动。伤害帧命中时若玩家处于无敌帧中 → 伤害无效
- **受伤**：HP > 0 时受击 → 无硬直（大型敌人不中断攻击），但闪烁反馈（白帧 2 帧）
- **死亡**：HP ≤ 0 → 立即禁用碰撞和 AI → 播放大型爆炸粒子（~600ms，分阶段碎裂）→ 标记待移除

**避障与寻路**：
- 小型和中型敌人使用**流场寻路**：每 N 帧（当玩家移动 >16px 时重算）在粗网格（16×16px 单元，60×34 = ~2000 单元）上运行一次 BFS。所有敌人采样流场方向替代直线方向。大型敌人直接使用直线追踪（体积大，通常不会被小型障碍物阻挡）
- 若流场计算未就绪（首帧）或竞技场无内部障碍物 → 回退为直线追踪

**生成规则**：由波次管理器（F6）控制生成时机和组合。敌人生成时 100-200ms 淡入动画——期间不可碰撞、不可伤害。生成交错（每帧 5-10 个，而非一帧全部生成）。

**死亡**：HP ≤ 0 → 立即禁用碰撞和 AI → 播放死亡动画 → 标记待移除。波次清空检测基于 HP ≤ 0 计数（非动画完成）。碰撞体移除延后至后续帧（5-10 个/帧），避免一帧大量移除导致物理服务器重载。

**性能约束**（50+ 同屏，240fps，≤4.17ms 帧预算）：
- 物理 tick rate：**60Hz**（非 240Hz）。渲染插值提供相同的视觉平滑度，物理负载降至 1/4
- 集中式敌人管理器：所有数据存于数组（struct-of-arrays 模式），统一 `_process` 更新。状态用 `enum` 打包，计时器用并行的 float 数组
- `MultiMeshInstance2D` 仅用于小型敌人（~40 实例，1 次绘制调用）。中型（10）和大型（3）使用独立 `Sprite2D` 节点——实例数少，MultiMesh 的复杂度/收益比为负
- 碰撞分离使用**空间哈希网格**（32px 单元）：每个敌人只查询相邻 9 个单元内的邻居，而非 O(N²) 全遍历。40 个小型敌人：~200 次距离检查 vs 780 次
- 中型敌人子弹使用 `Area2D`（轻量 overlap 检测），而非 `CharacterBody2D`（无物理响应需求）
- 禁止每个敌人独立运行 `_process()` ——管理器统一下发更新
- 小型敌人间保持至少 1px 背景间隙（碰撞半径 + 分离 steering 强制）

### States and Transitions

| 状态 | 小型 | 中型 | 大型 | 转换条件 |
|------|:--:|:--:|:--:|------|
| **待机** | — | — | 波次开始前 | 波次管理器激活 → 追逐/锁定 |
| **追逐/锁定** | ✅ 直线冲向玩家 | ✅ 维持 150-200px | ✅ 缓慢推进 60px/s | — |
| **攻击** | 接触伤害（碰撞重叠） | 射击（1.5-2s CD，250ms 前摇） | 近战（<80px，2-3s CD，400ms 前摇） | 距离条件满足 + 冷却就绪 |
| **受击冷却** | 接触后 200ms | — | — | 接触伤害后自动进入 |
| **受伤** | 白帧闪烁 2 帧 | 硬直 50ms + 闪烁 2 帧 | 闪烁 2 帧（无硬直） | HP 减少时触发 |
| **撤退** | — | 180px/s，最多 1.5s/250px | — | 距离 < 140px |
| **速射** | — | 连射 3 发（间隔 150ms） | — | 撤退被阻挡 >0.3s |
| **冲锋** | — | — | 500ms 前摇 + 250px/s 冲刺 1s | 每 5-8s 触发 |
| **死亡** | 碎裂粒子 ~200ms | 爆炸粒子 ~400ms | 大型爆炸 ~600ms | HP ≤ 0 |

## Formulas

### 敌人追踪

```
direction_to_player = (player_pos - enemy_pos).normalized()
velocity = direction_to_player × move_speed
# 若有流场数据可用，direction_to_player 替换为流场采样方向
```

### 中型距离保持（带滞后）

```
if distance < 140px:
    state = RETREAT        # 进入：140px
    velocity = away_from_player × 180px/s
elif distance > 210px:
    state = APPROACH        # 退出：210px
    velocity = toward_player × 120px/s
else:
    state = HOLD            # 滞后区间 [140, 210]
    velocity = Vector2.ZERO
```

滞后区间 70px（140→210）防止在阈值附近状态振荡。

### 中型射击

```
if state == HOLD and attack_cooldown_ready():
    telegraph_timer = 250ms  # 前摇
    # 前摇结束后：
    aim_dir = (player_pos - enemy_pos).normalized()
    bullet_spawn = enemy_pos + aim_dir × 10px
    bullet_velocity = aim_dir × 150px/s
    bullet_lifetime = 600px / 150px/s = 4s
    attack_cooldown = 1.5-2.0s（随机范围内取值）
```

### 大型冲锋

```
if charge_cooldown_ready():
    windup_timer = 500ms
    charge_direction = (player_pos_at_windup_start - enemy_pos).normalized()
    # 前摇结束后：
    velocity = charge_direction × 250px/s
    charge_duration = 1.0s
    charge_cooldown = 5-8s（随机范围内取值）
```

### 大型近战

```
if distance < 80px and melee_cooldown_ready():
    windup_timer = 400ms
    # 前摇结束后：
    if distance < 80px:  # 玩家仍在前摇期间未逃离
        deal_damage(2)
    melee_cooldown = 2-3s
```

### 碰撞分离（空间哈希）

```
GRID_CELL = 32px
# 每个敌人：查询所在单元 + 相邻 8 个单元（最多 9 单元）
neighbors = spatial_hash.query(enemy_pos, radius=GRID_CELL)
for neighbor in neighbors:
    if distance < min_separation:
        push_dir = (enemy_pos - neighbor_pos).normalized()
        enemy_pos += push_dir × separation_force × delta
```

## Edge Cases

- **50+ 小型敌人挤在一起**：空间哈希分离——最小间隙 1px。敌人密度过高时，外圈敌人减速形成自然分散。若空间仍不够，边缘敌人向外推开
- **中型被逼入墙角**：撤退被阻挡 >0.3s → 速射模式（3 发连射，间隔 150ms），然后尝试横向平移绕过障碍物。若所有方向均被阻挡 → 站桩速射（每 0.5s 一轮）
- **大型多个同时近战**：前摇独立计算。若两个大型同时在 80px 内，两个各自触发前摇——玩家需连续闪避两个攻击。伤害帧若在同一帧 → 伤害系统无敌帧只承受一次伤害
- **玩家在场景边缘被敌人围住**：敌人不会把玩家推出场景——碰撞只对敌人间有效（敌人不推玩家）。伤害系统配置"被 50+ 敌人挤在角落"→ 每 500ms 最多受击 1 次的 iframe 保证存活
- **敌人 AI 在玩家死亡后**：玩家死亡 → 所有敌人停止 AI 更新，冻结在当前位置。中型子弹冻结，大型前摇冻结（攻击不落地）。VFX 继续播放
- **大型敌人在波次过渡时存活**：波次过渡不清除存活敌人——新波次在现有敌人基础上增加
- **流场计算首帧**：竞技场加载后首帧流场可能未就绪 → 回退为直线追踪。第二帧流场就绪后平滑切换
- **技能 1 同时击杀 30+ 小型敌人**：死亡 VFX 立即全部播放（粒子池有足够容量）。碰撞体移除延后（5-10 个/帧），避免单帧大量移除导致物理服务器重载。音频：前 5-8 个死亡音效正常播放，超出部分静默丢弃
- **大型冲锋被闪避躲开**：若玩家在冲锋路径上按闪避 → 闪避位移 100px + 300ms 无敌帧。冲锋速度 250px/s × 0.3s = 最大 75px 位移。100px 闪避 > 75px 冲锋，可躲开。闪避方向需与冲锋方向垂直或反向

## Acceptance Criteria

### 核心行为

- **AC1**：**GIVEN** 小型敌人生成，**WHEN** 更新中，**THEN** 以 200±10px/s 直线冲向玩家位置。若有流场数据可用 → 沿流场方向移动
- **AC2**：**GIVEN** 小型敌人与玩家碰撞重叠，**WHEN** 接触伤害触发，**THEN** 玩家 HP-1，敌人进入受击冷却 200ms（不连续造成伤害），向后推开 10-15px
- **AC3**：**GIVEN** 中型敌人距离 > 210px，**WHEN** 更新中，**THEN** 以 120±10px/s 靠近玩家
- **AC4**：**GIVEN** 中型敌人距离 < 140px，**WHEN** 更新中，**THEN** 以 180±10px/s 撤退远离玩家。撤退期间不可射击
- **AC5**：**GIVEN** 中型敌人在 140-210px 范围内且攻击冷却就绪，**WHEN** 250ms 前摇完成，**THEN** 发射一颗可见像素子弹（150px/s，3×3px），子弹 4s 或 600px 后销毁

### 特殊行为

- **AC6**：**GIVEN** 中型敌人撤退被障碍物阻挡 >0.3s，**WHEN** 墙角行为触发，**THEN** 进入速射模式——连射 3 发（间隔 150±20ms），然后尝试横向平移
- **AC7**：**GIVEN** 大型敌人距离 < 80px 且近战冷却就绪，**WHEN** 400ms 前摇完成且玩家仍在范围内，**THEN** 玩家 HP-2。前摇期间敌人不移动
- **AC8**：**GIVEN** 大型敌人冲锋冷却就绪，**WHEN** 500ms 前摇完成，**THEN** 向锁定方向以 250±20px/s 冲刺 1s。前摇期间玩家可闪避逃离
- **AC9**：**GIVEN** 中型敌人 HP > 0 时被命中，**WHEN** 受击触发，**THEN** 暂停移动和攻击 50±10ms + 白帧闪烁 2 帧
- **AC10**：**GIVEN** 大型敌人 HP > 0 时被命中，**WHEN** 受击触发，**THEN** 不中断当前动作，但闪烁反馈（白帧 2 帧）

### 死亡

- **AC11**：**GIVEN** 小型敌人 HP=1，**WHEN** 被 1 发子弹命中，**THEN** 立即死亡——碰撞/AI 禁用，碎裂粒子播放，HP ≤ 0 计入波次清空计数
- **AC12**：**GIVEN** 中型敌人 HP=3，**WHEN** 被命中 3 次，**THEN** HP=0 时死亡——碰撞/AI 禁用，爆炸粒子播放 ~400ms 后移除
- **AC13**：**GIVEN** 技能 1 同时击杀 30+ 小型敌人，**WHEN** 死亡处理，**THEN** 所有死亡 VFX 立即播放，碰撞体移除延后至后续帧（每帧 5-10 个），帧时间 ≤ 4.17ms

### 性能

- **AC14**：**GIVEN** 40 小型 + 10 中型 + 3 大型 = 53 敌人在场景中全部活跃，**WHEN** Gameplay 帧更新（物理 60Hz，渲染 240fps），**THEN** 帧时间 ≤ 4.17ms。测试条件：所有敌人追踪玩家，中型射击中，技能 1 爆发（800 粒子峰值），玩家满射速射击

### 交互

- **AC15**：**GIVEN** 玩家死亡，**WHEN** 死亡事件触发，**THEN** 所有敌人 AI 冻结（停止移动/攻击），在途子弹冻结，前摇冻结，VFX 继续播放

## Open Questions
