# 升级卡片 UI

> **Status**: Approved
> **Author**: user + agents
> **Last Updated**: 2026-05-07

## Overview

升级卡片 UI 是波次结束时玩家进行构筑选择的界面——3 张卡片从底部滑入，拱形排列，中间卡片略上浮。每张卡片 180×240px，2px 纯白像素边框+厚角，深钢蓝底色 85% 不透明度（透出模糊战场）。玩家点击选择后，选中卡片放大闪白→飞入屏幕中心吸收，未选卡片淡出。完整视觉规格见美术圣经 §7。

## Detailed Design

**卡片结构**：图标区（64×64px 像素符号 + 冷青装饰框）+ 名称（12px 粗体）+ 描述（8px 常规，最多 2 行）

**动画**：暗角加深→三卡错开滑入（总 0.6s）→选择→飞入吸收（0.3s）→暗角恢复

**交互**：点击选中。去抖 500ms——选中后不接受再次点击。键盘快捷键（1/2/3）可选。

## Interactions

| 系统 | 接口 |
|------|------|
| 构筑系统（F5） | 选项数据 + 选择回调 |
| 波次管理（F6） | 波次过渡信号 |

## Acceptance Criteria

- **GIVEN** 波次过渡，**WHEN** 暗角加深完成，**THEN** 3 张卡片从底部滑入，中间卡片上浮 8px
- **GIVEN** 卡片展示中，**WHEN** 点击 1 张，**THEN** 选中卡放大+闪白+飞入吸收，其余淡出
- **GIVEN** 刚选中卡片，**WHEN** 500ms 内再次点击，**THEN** 忽略
- **GIVEN** 卡片显示中，**WHEN** 查看卡片，**THEN** 每张包含图标+名称+描述
