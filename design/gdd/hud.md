# HUD

> **Status**: Approved
> **Author**: user + agents
> **Last Updated**: 2026-05-07

## Overview

HUD 显示战斗中的辅助信息——顶部波次计数和击杀数、底部武器图标和技能冷却。所有信息 50% 不透明度常态显示，信息变化时升至 85%。释放瞬间降至 20%（C2 视觉独占权）。完整布局和视觉规格见美术圣经 §7。

## Detailed Design

**布局**（960×540）：

```
┌──────────────────────────┐
│ WAVE 5          x 47    │  顶部：8px 像素字体，50%不透明度
│                          │
│    [角色+Diegetic UI]     │  中央
│                          │
│ [武器]  [技能1冷却] [技能2] │  底部：16px图标+8px文字
└──────────────────────────┘
```

**不透明度策略**：常态 50% → 信息变化 85%（0.5s）→ 回落 50%。释放瞬间 → 20%。

## Interactions

| 系统 | 接口 |
|------|------|
| 波次管理（F6） | 波次数字 |
| 射击系统（C2） | 击杀计数 |
| 技能系统（C4） | 冷却倒计时 |

## Acceptance Criteria

- **GIVEN** 当前波次=5，**WHEN** 战斗中，**THEN** 顶部显示 "WAVE 5"（50%不透明度）
- **GIVEN** 击杀 47 个敌人，**WHEN** 战斗中，**THEN** 显示 "x 47"
- **GIVEN** 技能 1 冷却剩余 8s，**WHEN** 战斗中，**THEN** 底部显示技能图标+ "8"
