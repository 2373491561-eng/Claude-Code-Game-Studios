# Diegetic UI

> **Status**: Approved
> **Author**: user + agents
> **Last Updated**: 2026-05-07
> **Implements Pillar**: 闪避即武器（P1）— 闪避充能光点；每一枪都要有感觉（P2）— 充能球反馈

## Overview

Diegetic UI 是直接显示在角色身上的战斗信息层——脚下分段光环（血量）、背后悬浮充能球（技能充能状态）、环绕光点（闪避剩余次数）。战斗中所有关键信息在角色身上或周围，玩家不需要将视线移到屏幕角落。它遵循美术圣经 §7 的完整定义，是 C1 铁律（0.2 秒定位角色状态）的实现载体。

## Player Fantasy

Diegetic UI 追求的幻想是"你在角色身上看到一切"。血量见底时，脚下光环只剩最后一段在闪烁——你知道自己离死亡只差一次受击。充能球从冷青转为电光蓝、中央亮起橙红脉动——你知道技能就绪了。环绕的光点一颗颗熄灭——你知道闪避快用完了。你不需要看血条、读数字——你只需要看角色。

## Detailed Design

完全按照美术圣经 §7 定义实现：

- **血量光环**：圆形分段环，20px 半径，1px 弧段，段间 1px 空隙。受击段碎裂→飞出碎片，回血段渐亮
- **技能充能球**：12-14px 直径，角色背后悬浮。四态：灰蓝（空）→ 冷青（充能中）→ 电光蓝（满）→ 电光蓝+橙红脉动（可释放）。200ms 平滑过渡
- **闪避光点**：3×3px 菱形，28px 轨道，慢速旋转。冷青脉冲（可用）→ 灰蓝静止（冷却中）。消耗=白闪+收缩消失，恢复=弹出+亮闪

## Interactions

| 系统 | 接口 |
|------|------|
| 伤害系统（C5） | 血量变化 → 光环段更新 |
| 技能系统（C4） | 冷却进度 → 充能球颜色/动画 |
| 闪避系统（C3） | 充能次数 → 光点状态 |

## Acceptance Criteria

- **GIVEN** 血量=3，**WHEN** 满血，**THEN** 光环 3 段全亮纯白
- **GIVEN** 受击，**WHEN** 血量-1，**THEN** 光环 1 段碎裂消失
- **GIVEN** 技能冷却中，**WHEN** 充能进度 50%，**THEN** 充能球冷青色
- **GIVEN** 技能就绪，**WHEN** 冷却归零，**THEN** 充能球电光蓝+橙红脉动
- **GIVEN** 闪避充能=2/3，**WHEN** 查看光环，**THEN** 2 个光点亮冷青，1 个暗灰蓝
