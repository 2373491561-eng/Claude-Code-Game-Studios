# 闪避系统

> **Status**: In Review (revised v2)
> **Author**: user + agents
> **Last Updated**: 2026-05-08 (re-review revision)
> **Implements Pillar**: 闪避即武器（P1）— 闪避是这个游戏的存在意义

## Overview

闪避系统是《裂隙反应》的灵魂——它不只是保命手段，它是资源管理、进攻引擎和操作检验的统一体。Shift 或鼠标右键触发闪避：3 次充能，随时间缓慢恢复。普通闪避消耗充能，提供无敌帧。极限闪避（子弹在判定距离内时按下闪避）不消耗充能、充能≥1 时触发时间缩放和进攻奖励、并恢复血量加护盾。充能=0 时极限闪避仍可用（仅无敌帧），保留了绝境中的操作求生空间。每一次闪避都是一次资源决策——乱闪会耗尽充能，精准操作能让你从绝境中翻盘。它直接服务于支柱 1 "闪避即武器"和整个 30 秒核心循环。

## Player Fantasy

闪避追求的幻想是"万军之中，刀尖起舞"。当屏幕上 50+ 敌人同时冲来，你不是靠数值硬扛——你靠的是这一次 Shift 的时机是否精准。普通闪避让你活下来，极限闪避让你反杀——时间冻结的那一帧，屏幕偏蓝、敌人减速、你的手指已经按下了反击的方向。闪避不是"按一下躲开"——它是"我赌上这一刻"。

## Detailed Design

### Core Rules

**闪避充能**：初始 3 次充能。普通闪避消耗 1 次。充能随时间自动恢复（1 次 / 3 秒）。充能次数由环绕角色的冷青光点显示。充能向下取整显示（charge=0.6 时显示 0 次可用）。充能=0 时无法触发普通闪避——但极限闪避始终可用（保留操作求生空间）。充能≥1 时：普通闪避可用，极限闪避的进攻奖励（时间缩放、护盾、技能 CD 缩减）生效。充能=0 时：极限闪避仅提供无敌帧（300ms），无时间缩放、无护盾、无回血、无 CD 缩减。这是对资源管理失误的惩罚——丧失进攻节奏，而非彻底失去防御能力。

**双通道触发**：Shift 键 / 鼠标右键，任一按下触发。两个按键均映射至同一 `dodge` 动作（Godot Input Map）。处理顺序：先去抖（50ms 窗口内多次按下合并为 1 次）→ 再缓冲（当前动作结束前 100ms 内按下，结束后自动触发下一次）。去抖和缓冲均在 `_input(event)` 中基于 `Time.get_ticks_msec()` 毫秒级精度处理。

**普通闪避**：
- 动画：角色向闪避方向快速滑步（dash），保持面朝方向不变，带轻微动态模糊。闪避期间碰撞层切换为穿透敌人（不阻挡位移），位移被障碍物截断时停在障碍物边缘，但无敌帧保持完整 300ms（不受位移截断影响）
- VFX：闪避起点生成 2-3 个像素烟尘粒子（dust puff），闪避终点生成 1-2 个环形像素波纹（landing ripple）
- 消耗 1 次充能（充能≥1 时可用；充能=0 时普通闪避不可用）
- 方向 = 当前移动方向（归一化）；无移动输入时 = 最后移动方向；从未移动过 = 向鼠标瞄准反方向闪避（向后闪）
- 位移距离：100px（斜向归一化后仍为 100px，不会因对角线输入而变长）
- 持续时间：~300ms 真实时间（使用 `Time.get_ticks_msec()` 计时，不受 `Engine.time_scale` 影响）
- 全程无敌帧（300ms），无敌帧不受位移截断影响——即使撞墙，300ms 无敌帧仍然完整
- 普通闪避不恢复血量

**极限闪避**：
- 前置条件：始终可触发（即使充能=0）。充能≥1 时触发可获得完整进攻奖励；充能=0 时仅提供无敌帧（300ms），无进攻奖励
- 判定方式：按下闪避时，检测是否有敌方子弹/攻击在角色 40px 范围内（距离判定——子弹中心到玩家中心的欧几里得距离，即 `(bullet.global_position - player.global_position).length() <= 40`）
- 不消耗充能次数
- 全程无敌帧（300ms，与普通闪避相同）
- 充能≥1时触发时间缩放：`Engine.time_scale = 0.2`，持续 200ms 真实时间后以 ease-out-expo 缓动恢复至 1.0（`time_scale_recovery(t) = 1.0 - 0.8 × e^(-6t)`，t 从 0 到 1 对应 200ms，t≥1 时硬钳位至 1.0）。时间缩放仅影响敌人、子弹、VFX 和摄像机——闪避自身位移计时使用真实时间，不受时间缩放影响
- 视觉（充能≥1时）：屏幕冷色滤镜偏移（偏蓝）+ 画面边缘锐化 + 角色残影加强（残影色调偏冷蓝）
- 音效（充能≥1时）：冷冽时间音效 + 音高下降 2 个八度（通过 `AudioStreamPlayer.pitch_scale` 显式设置，`Engine.time_scale` 不影响 AudioServer）
- 充能≥1时：恢复 1 点血量（闪避触发帧立即生效）+ 额外 1 次护盾（优先消耗，持续 3 秒）。充能=0时：不回血、无护盾
- 充能≥1时缩短技能 1 冷却：普通闪避 -3s，极限闪避 -8s（见技能系统 GDD）。充能=0时：不缩短 CD
- 充能≥1时触发 skill_2 窗口（极限闪避后 500ms 内的下一次攻击自动附加 skill_2 效果）
- 多枚敌方攻击同时在 40px 内：只触发 1 次极限闪避，效果不叠加
- 极限闪避进行中再次触发极限闪避：第二次被忽略（时间缩放不叠加、不重置）

**闪避期间**：
- 移动输入被忽略（闪避方向由触发时锁定，velocity = 0）
- 瞄准方向锁定（闪避期间不更新瞄准角度）
- 射击暂停（停止生成子弹）。闪避结束后：若射击键从未松开 → 自动恢复射击；若松开后重新按下 → 随新按下恢复射击
- 技能 1 仍可释放（空格键不锁定），且技能 1 释放期间可闪避取消（见技能系统 GDD）
- 闪避动画期间（前 300ms）再次按下闪避键：当前闪避结束前 100ms 内的按下进入输入缓冲，其余时间按下被忽略

### States and Transitions

| 状态 | 触发 | 持续 | 可操作 |
|------|------|------|:--:|
| **就绪** | 充能 ≥ 1 | 常态 | 移动+射击+技能 |
| **普通闪避中** | 按下闪避键（充能≥1，无攻击在40px内） | ~300ms 真实时间 | 仅技能 1 |
| **极限闪避中（充能≥1）** | 按下闪避键（敌方攻击在40px内，充能≥1） | ~300ms 位移 + 200ms 时间缩放恢复 | 仅技能 1 |
| **极限闪避中（充能=0）** | 按下闪避键（敌方攻击在40px内，充能=0） | ~300ms 位移，无时间缩放 | 仅技能 1 |
| **冷却中** | 充能 < 1（普通闪避消耗后或恢复中） | 等恢复至 ≥1 | 移动+射击+技能+极限闪避（仅无敌帧） |

## Formulas

### 充能恢复

`charge_regen_time = 3.0s`（每恢复 1 次的时间）

`charge = min(charge + delta/regen_time, max_charge)`

`can_dodge = floor(charge) >= 1`（充能向下取整——charge=0.6 时不能闪避）

充能恢复计时仅在非闪避期间累加——闪避开始时暂停，闪避结束时恢复。极限闪避时暂停总时长 = 300ms（位移）+ 200ms（时间缩放恢复）= 500ms。使用 `_physics_process(delta)` 固定步长累加，确保帧率无关。

### 极限闪避判定

`is_perfect = any enemy attack distance to player <= PERFECT_DISTANCE`

- 距离定义：敌方攻击来源（子弹中心、接触敌人中心、近战范围边界）到玩家中心的欧几里得距离（`(attack_source.global_position - player.global_position).length() <= 40`）。所有攻击类型——子弹、接触敌人逼近、近战范围攻击——均可触发
- 极限闪避始终可触发（即使充能=0）。充能≥1 时获得完整进攻奖励（时间缩放、回血、护盾、CD 缩减、skill_2 窗口）；充能=0 时仅无敌帧
- 多枚敌方攻击同时在范围内：只判定 1 次极限闪避
- 极限闪避进行中再次触发：忽略（不叠加、不重置时间缩放计时器）

### 闪避位移

`dodge_direction_normalized = normalize(input_direction)`

`target_position = player_pos + dodge_direction_normalized × 100px`

每帧位移实现（替代原伪代码 `sweep_collision`——Godot 中不存在此函数）：
```
# 每 _physics_process 帧：
var step = dodge_speed * get_physics_process_delta_time()
var collision = move_and_collide(step)
if collision:
    # 位移在碰撞点截断，但无敌帧保持完整 300ms
    break
```
> ⚠️ **关键实现警告**：闪避位移必须使用 `get_physics_process_delta_time()` 而非 `delta` 参数。因为 `Engine.time_scale = 0.2` 期间 `delta` 会被缩放（约 0.0033s），导致玩家以 1/5 速度移动。`get_physics_process_delta_time()` 返回不受缩放的固定步长。

- 输入方向在计算前归一化——对角线输入位移 100px，而非 141px
- 位移使用 `CharacterBody2D.move_and_collide()` 逐帧沿闪避方向检测障碍物。碰到障碍物时停止在碰撞点，位移截断，但无敌帧保持完整 300ms
- 闪避期间玩家碰撞层切换：通过 `collision_mask` 位操作排除敌人碰撞层（允许穿透敌人），保留障碍物碰撞层
- 位移进度使用真实时间追踪（`Time.get_ticks_msec()`），不受 `Engine.time_scale` 影响
- 300ms 结束时最后一个物理帧可能无法精确对齐帧边界（~16ms 误差）——允许最后一帧略微超调，AC 中 ±5px 容差已覆盖此误差

### 时间缩放恢复缓动

`time_scale_recovery(t) = clamp(1.0 - 0.8 × e^(-6t), 0.2, 1.0)`

其中 t 从 0（时间缩放结束帧）到 1（200ms 后），使用 ease-out-expo 曲线。**t ≥ 1.0 时硬钳位至 1.0**——注意 f(1) ≈ 0.9980，曲线本身不精确到达 1.0，必须显式钳位（否则依赖 `time_scale == 1.0` 的系统永远不会解除门控）。时间缩放仅应用于敌人、子弹、VFX 和摄像机——闪避自身 `_physics_process` 中的位移计算使用 `get_physics_process_delta_time()`（不受缩放影响的固定步长）。

### 技能冷却缩短（交叉引用）

- 普通闪避成功：`skill_1_cooldown -= 3.0s`（不少于 0）
- 极限闪避成功（充能≥1）：`skill_1_cooldown -= 8.0s`（不少于 0）
- 极限闪避成功（充能=0）：不缩短 CD
- 冷却已就绪（cooldown ≤ 0）时闪避不额外减少冷却
- 详见 `design/gdd/skill-system.md` Formulas 节

### skill_2 窗口

`skill_2_window_active = (time_since_perfect_dodge < 0.5s) AND (attack_triggered)`

极限闪避后 500ms 真实时间内，下一次攻击自动附加 skill_2 效果。500ms 后窗口关闭，不累积。详见 `design/gdd/skill-system.md`

## Edge Cases

- **充能 = 0 时按下闪避（附近无子弹）**：普通闪避不可用——不消耗、不位移、不无敌。沉默反馈（不播放音效）
- **充能 = 0 时按下闪避（附近有攻击）**：触发极限闪避——仅提供无敌帧（300ms）。无时间缩放、无回血、无护盾、无技能 CD 缩减。沉默反馈（不播放时间音效，普通闪避音效仍播放）
- **极限闪避 + 技能爆发同时触发**：极限闪避的时间缩放先执行，爆发等待时间恢复后再触发（已由音频 GDD 定义）
- **闪避方向无移动输入**：使用最后移动方向（`last_move_dir` 持久化向量，跨站立不动和场景切换保留）。如果从未移动（`last_move_dir == Vector2.ZERO`——游戏刚开始的哨兵状态），向鼠标瞄准的反方向闪避（向后闪）。`normalize()` 调用前必须检查零向量——若方向为零则默认为 `Vector2(1, 0)`（向右），避免除零
- **充能恢复至满时仍在闪避中**：充能暂停恢复——闪避期间不恢复充能，闪避结束才继续计时。极限闪避时暂停总时长 500ms（300ms 位移 + 200ms 时间缩放恢复），三次连续极限闪避累计损失 1.5s 恢复时间（约 0.5 次充能）
- **两个敌人同时攻击、都在完美窗口内**：只判定 1 次极限闪避——取最近的攻击。时间缩放和无敌帧不叠加
- **闪避位移后的位置在障碍物内**：闪避位移被障碍物截断——停在障碍物边缘。无敌帧保持完整 300ms（不受位移截断影响），即使第 1 帧就撞墙。闪避仍消耗 1 次充能（普通闪避）
- **闪避位移后的位置在敌人碰撞体内**：闪避期间穿透敌人——允许位移穿过敌人。闪避结束时若仍在敌人内部，自动推出至最近空位（以玩家中心为起点螺旋搜索，最大搜索半径 200px）。若 200px 内无空位（极端情况：被 50+ 敌人挤在走廊死角），玩家受到 1 点伤害并强制推到最近的非重叠位置
- **闪避触发帧与伤害帧重合**：闪避输入优先——先设置无敌帧再处理伤害。即闪避触发帧上玩家不受伤害，回血在闪避触发帧立即生效（极限闪避、充能≥1 时）
- **闪避触发帧与子弹生成帧重合**：攻击检测发生在 `_input` 事件处理时。若攻击在同一帧的 `_physics_process` 中生成（`_input` 之后），该攻击对本次距离检测不可见——这是一个已知的罕见边界情况，不修正（检测窗口无法预测未来帧的攻击）
- **输入缓冲与去抖重叠**：去抖先于缓冲执行。同一 50ms 窗口内的多次按键先去抖合并为 1 次，然后该合并结果进入缓冲判断
- **极限闪避期间再次触发极限闪避**：第二次被忽略——time_scale 不叠加（不会 0.2 × 0.2 = 0.04），时间缩放计时器不重置
- **死亡瞬间按下闪避**：闪避不触发——死亡状态优先于所有输入
- **暂停菜单打开时按下闪避**：闪避不触发——暂停状态屏蔽所有游戏输入

## Dependencies

- **上游依赖**：输入系统 F1（`dodge` 信号）、玩家移动 C1（移动方向）
- **下游依赖**：伤害系统 C5（无敌状态）、技能系统 C4（极限闪避奖励）、摄像机 F4（震动+时间缩放）
- **循环依赖 C3 ↔ C5**：闪避提供 `is_invincible()` 和 `get_charge_count()` 公共接口，伤害系统只读取，不依赖闪避内部实现

## Tuning Knobs

| 参数 | 默认值 | 安全范围 | 说明 |
|------|-------|---------|------|
| 最大充能次数 | 3 | 2-5 | 太少闪避太稀缺，太多无资源管理压力 |
| 充能恢复时间 | 3s/次 | 2-5s | 太快闪避无限，太慢只能靠极限闪避 |
| 极限闪避判定距离 | 40px | 20-50px | 中心到中心距离。涵盖所有攻击类型（子弹、接触、近战）。40px 时在 25 发子弹同屏场景下约 22% 概率意外触发——若 playtest 反馈太容易触发，可下调至 30px 或增加时机窗口 |
| 闪避位移距离 | 100px | 60-150px | 太短躲不开范围攻击，太远失控 |
| 闪避持续时间 | 300ms | 200-400ms | 影响闪避手感和可操作间隔。300ms 偏向"有重量感的闪避"，若 playtest 反馈偏慢可下调至 200-250ms |
| 时间缩放强度 | 0.2 | 0.1-0.4 | 0.1=几乎冻结，0.4=略慢。代码级安全钳：`max(time_scale, 0.01)` 防止软锁 |
| 时间缩放持续 | 200ms | 100-300ms | 太短没感觉，太长打断战斗节奏 |
| 时间缩放缓动曲线 | ease-out-expo | — | `f(t) = clamp(1.0 - 0.8 × e^(-6t), 0.2, 1.0)`，t ∈ [0,1]。t≥1.0 时硬钳位至 1.0（曲线渐近值约 0.998，不钳位会导致依赖 `time_scale == 1.0` 的系统永远无法解除门控）。不可改为 linear——线性恢复会有"啪"的跳变感 |
| 充能恢复时间除数 | 3.0s | — | 代码级安全钳：`max(regen_time, 0.001)` 防止除零 |

## Visual/Audio Requirements

**视觉**：
- **普通闪避**：角色滑步动画（dash）——快速横向位移，面朝方向不变。残影轨迹 2-3 个渐淡半透明复制帧，方向与闪避方向一致。闪避起点：2-3 个像素烟尘粒子（dust puff，3x3px 灰色）。闪避终点：1-2 个环形像素波纹（landing ripple，白色渐淡）
- **极限闪避**：全屏冷色滤镜（偏蓝）+ 画面边缘锐化 + 时间缩放 + 角色残影加强（色调偏冷蓝）。残影帧数增至 4-5 个。角色在时间缩放期间保持正常速度——视觉上呈现"世界凝固、我在动"的对比
- **充能光点**：Diegetic UI 3×3px 菱形光点，冷青 = 可用，灰蓝 = 冷却中（已在美术圣经 §7 定义）。充能值向下取整显示——charge=0.6 时显示 0 个光点亮起
- **角色动画资产需求**：4 方向滑步精灵（上/下/左/右），每方向约 6-8 帧，精灵分辨率与角色匹配（参考美术圣经角色规格）

**音频**：
- 普通闪避：快速位移音效（whoosh 类）
- 极限闪避：冷冽时间音效 + 音高下降 2 个八度（通过 `AudioStreamPlayer.pitch_scale` 显式设置）。普通闪避音效也在时间缩放期间保持正常音高（pitch_scale = 1.0），仅世界音效下降

## Acceptance Criteria

### 核心功能

- **AC1a**：**GIVEN** 充能=3，玩家按住 W（上方向），**WHEN** 按 Shift，**THEN** 角色向上方位移 100±5px（中心到中心），充能=2
- **AC1b**：**GIVEN** 充能=3，玩家无移动输入（静止）但有最后移动方向（如上次向右走），**WHEN** 按 Shift，**THEN** 角色向右方位移 100±5px
- **AC1c**：**GIVEN** 充能=3，闪避路径上有障碍物（距离 <100px），**WHEN** 按 Shift，**THEN** 角色位移在障碍物边缘截断，充能仍递减至 2，但无敌帧保持完整 300ms（不受位移截断影响）

### 充能与限制

- **AC2a**：**GIVEN** 充能=0，附近无敌方攻击（40px 内无攻击），**WHEN** 按 Shift，**THEN** 无任何反应——不位移、不无敌、不消耗充能
- **AC2b**：**GIVEN** 充能=0，敌方攻击距玩家 ≤40px，**WHEN** 按 Shift，**THEN** 触发极限闪避——300ms 无敌帧，但无时间缩放、无回血、无护盾、无技能 CD 缩减、无 skill_2 窗口
- **AC6a**：**GIVEN** 充能从 1 递减至 0（闪避消耗），**WHEN** 该次闪避动画结束（300ms 后），**THEN** 充能恢复计时器开始，3.0±0.1 秒后充能=1
- **AC6b**：**GIVEN** 充能恢复计时器运行中（已恢复 1.5 秒），**WHEN** 玩家执行另一次闪避，**THEN** 闪避期间充能恢复暂停，闪避结束后恢复计时继续（不是重置）

### 极限闪避

- **AC3a**：**GIVEN** 充能≥1，敌方攻击距玩家中心 ≤40px（`(attack_source.global_position - player.global_position).length() <= 40`），**WHEN** 按 Shift，**THEN** 触发极限闪避——充能不消耗，`Engine.time_scale` 设为 0.2，持续 200ms 后以 ease-out-expo 恢复，t≥1.0 时硬钳位至 1.0
- **AC3b**：**GIVEN** 极限闪避触发且充能≥1，**THEN** 全屏叠加冷色滤镜（`blue_tint = 0.15`），画面边缘锐化效果激活，参考截图 `refs/perfect_dodge_screen.png` 验证视觉匹配
- **AC3c**：**GIVEN** 多枚敌方攻击同时在 40px 范围内（≥2 个），**WHEN** 按 Shift，**THEN** 极限闪避只触发 1 次，time_scale 保持 0.2 不叠加
- **AC3d**：**GIVEN** 充能=0，敌方攻击 ≤40px，**WHEN** 按 Shift，**THEN** 触发极限闪避——300ms 无敌帧，但 time_scale 保持 1.0（无缩放），无冷色滤镜，无画面锐化，无回血，无护盾，无 CD 缩减

### 闪避期间约束

- **AC4**：**GIVEN** 闪避动画中（按下 Shift 帧起 300ms），**WHEN** 尝试按 WASD 移动或按左键射击，**THEN** velocity = (0,0)，无子弹生成，瞄准方向不变
- **AC9**：**GIVEN** 闪避进行中（300ms 内，包括位移被障碍物截断的情况），**WHEN** 任意敌方攻击命中玩家，**THEN** 不造成伤害（全程无敌帧，不受位移截断影响）

### 射击恢复

- **AC5a**：**GIVEN** 闪避前按住射击，闪避期间射击暂停，**WHEN** 闪避结束（玩家从未松开射击键），**THEN** 射击自动恢复
- **AC5b**：**GIVEN** 闪避期间松开了射击键又重新按下，**WHEN** 闪避结束，**THEN** 射击随新按下恢复（无需额外操作）

### 极限闪避奖励

- **AC7a**：**GIVEN** 极限闪避成功且充能≥1，**WHEN** 闪避结束后 500ms 窗口内执行攻击动作，**THEN** 该次攻击的输出（伤害值、弹丸数或范围）与窗口外攻击不同——通过连续 10 次窗口内攻击 vs 10 次窗口外攻击的对比验证，输出差异具有统计显著性（p < 0.01）。skill_2 的具体修改量由构筑系统定义（参见 `design/gdd/skill-system.md` AC-3）
- **AC7b**：**GIVEN** 极限闪避成功但充能=0，**WHEN** 闪避结束后 500ms 内执行攻击动作，**THEN** 该次攻击为普通攻击，不附加 skill_2 效果
- **AC10**：**GIVEN** 极限闪避成功且充能≥1，**WHEN** 闪避触发，**THEN** 角色获得 1 次护盾（优先消耗，持续 3 秒）。护盾持续期间受击先扣护盾，护盾消失后才扣血量。充能=0 时极限闪避不获得护盾

### 输入处理

- **AC8a**：**GIVEN** Shift 和鼠标右键均映射至 `dodge` 动作，**WHEN** 两键在 50ms 内先后按下，**THEN** 仅触发 1 次闪避（去抖生效）
- **AC8b**：**GIVEN** Shift 和右键间隔 >50ms 按下，充能=3，**WHEN** 第二次按下，**THEN** 触发第二次闪避——充能=1
- **AC11**：**GIVEN** 闪避方向为斜向（如同时按住 W+D），**WHEN** 按 Shift，**THEN** 闪避位移 100±5px（方向向量已归一化，非 141px）
- **AC12**：**GIVEN** 闪避动画剩余 ≤100ms 时再次按下 Shift，**WHEN** 当前闪避结束，**THEN** 自动触发下一次闪避（充能可用时）。输入缓冲在闪避结束后 1 帧内兑现

## Open Questions

- **充能恢复是否受构筑影响**：是否有升级选项加速充能恢复或增加上限？MVP 不涉及，预留 `charge_regen_multiplier` 和 `max_charge_bonus` 全局变量供后续升级系统修改
- **无移动方向时的闪避方向**：已决定——从未移动过的新生角色向鼠标瞄准反方向闪避（向后闪）。合理性已用 playtest 验证标记，需在实际游戏中确认手感
- **闪避是否穿过敌人**：已决定——穿透。闪避期间碰撞层排除敌人碰撞（Layer 3），闪避结束后恢复。这是已完成的设计决策，不再作为开放问题
