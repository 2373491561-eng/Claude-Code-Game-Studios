# 伤害与血量

> **Status**: Approved
> **Author**: user + agents
> **Last Updated**: 2026-05-08 (design-review revision — 7 blockers resolved, formulas fixed, ACs expanded to 20)
> **Implements Pillar**: 闪避即武器（P1）— 极限闪避回血；压迫与释放（P4）— 血量归零的死亡时刻

## Overview

伤害与血量系统定义了《裂隙反应》中"活着"和"死去"的规则。玩家血量不是数值条——而是可承受的攻击次数（初始 3 点）。每次受击扣除的 HP 取决于敌人类型——小型敌人每次 1 点，大型敌人每次 2 点。HP 归零则死亡。极限闪避成功（充能≥1）可以恢复血量——这正是"闪避即武器"在生存层面的含义：精准操作 = 生存。受击后有短暂的无敌帧，防止被连续击中瞬间死亡。极限闪避检测覆盖所有敌方攻击类型——子弹、接触敌人逼近、近战范围攻击——只要在 40px 范围内按下闪避即可触发。敌人的伤害和血量由各自类型定义——小型杂兵一枪秒杀，大型敌人需要多枪。

## Player Fantasy

血量系统追求的是"刀尖上的每一次呼吸"。当你的血量只剩 1 次、屏幕上 50+ 敌人正在逼近——你知道一次精准的极限闪避就能恢复血量、把局势扳回来。血量不是资源条，它是心跳——每一次减少都是"差一点就死了"，每一次恢复都是"我靠自己活了下来"。

## Detailed Design

### Core Rules

**玩家血量**：数值制。默认最大血量 = 3 点。受击扣减 = 敌人伤害值（小型/中型 1 点，大型 2 点）。HP ≤ 0 = 死亡。

**受击无敌帧**：受到伤害后有 500ms 无敌帧。无敌期间不会再次受击。无敌帧结束前 100ms 角色闪烁提示。

**闪避回血**（与闪避 GDD v2 对齐）：
- 普通闪避：不恢复血量
- 极限闪避（充能=0）：不恢复血量，无护盾
- 极限闪避（充能≥1）：恢复 1 点血量（不超过最大值）+ 额外护盾（1 次，优先消耗，持续 3 秒真实时间）

**极限闪避检测范围**（与闪避 GDD v2 对齐）：所有敌方攻击类型——子弹、接触敌人逼近、近战范围攻击——在玩家 40px 范围内均可触发极限闪避。检测使用欧几里得距离（中心到中心）。多目标同时在范围内只触发 1 次。

**敌人血量**：每种敌人类型有独立的 HP 值（受击次数或数值）。

| 敌人层级 | HP | 说明 |
|---------|:--:|------|
| 小型虫群 | 1 | 一枪一个 |
| 中型类人 | 3 | 需要多枪 |
| 大型块状 | 8 | 重装，需要集中火力 |

**玩家伤害**：基础每发子弹伤害 = 1（由构筑升级可提升）。

**死亡**：血量归零 → 战斗冻结（500ms）→ 切换到死亡结算场景。

**受击反馈**：
- 屏幕震动（低强度，100ms）
- 角色受击闪烁（白帧 2 帧）
- 血量光环段碎裂动画
- 受击音效

### States and Transitions

| 状态 | 说明 |
|------|------|
| **正常** | 可受击 |
| **无敌** | 受击后 500ms，不受伤害 |
| **护盾** | 极限闪避后 3s，优先消耗 |
| **死亡** | HP=0，冻结中 |

### Interactions with Other Systems

| 系统 | 接口 |
|------|------|
| 闪避系统（C3） | 读取 `is_invincible()` / `get_charge_count()`；极限闪避成功（充能≥1）→ 回血信号 + 护盾 |
| 射击系统（C2） | 命中事件 → 造成伤害值 |
| 敌人系统（C6） | 敌人碰撞 → 玩家受击；玩家子弹命中 → 敌人扣血 |
| Diegetic UI（P2） | 血量光环段数更新 |
| VFX（P1） | 受击粒子 + 闪烁 |
| 音频（F3） | 受击音效 + 死亡音效 |
| 摄像机（F4） | 受击震动 + 死亡震动 |

## Formulas

### 受击

```
# 传入伤害值（由敌人类型决定：小型=1、中型=1、大型=2）
incoming_damage = enemy.contact_damage  # 或 enemy.projectile_damage（中型射击）
if not is_invincible():
    # 护盾优先消耗
    remaining = incoming_damage - shield
    shield = max(shield - incoming_damage, 0)
    if remaining > 0:
        hp -= remaining
        trigger_invincibility_frames()  # 仅 HP 实际减少时触发
    # 若 remaining ≤ 0：护盾完全吸收，不触发无敌帧
```

```
is_dead = (hp <= 0)
```

**变量表**：

| 符号 | 类型 | 范围 | 说明 |
|------|------|------|------|
| incoming_damage | int | 1-2 (MVP) | 敌人造成的伤害值 |
| remaining | int | 0-incoming_damage | 穿透护盾后的剩余伤害 |
| shield | int | 0-1 (MVP 最大 1) | 当前护盾层数 |
| hp | int | 0-max_hp | 玩家当前血量 |

### 回血

```
if hp > 0:  # 死亡优先——已死亡玩家不接受回血
    hp = min(hp + 1, max_hp)
```

### 护盾倒计时

护盾使用真实时间计时（`Time.get_ticks_msec()`，不受 `Engine.time_scale` 影响）：

```
shield_expiry_ms = Time.get_ticks_msec() + (shield_duration_s × 1000)
# 每帧：if Time.get_ticks_msec() >= shield_expiry_ms: shield = 0
```

### 死亡冻结

```
if is_dead and not death_frozen:
    death_frozen = true
    death_freeze_start_ms = Time.get_ticks_msec()
    # 冻结：所有敌人 AI + 子弹 + 玩家输入。VFX 和摄像机继续播放。
if is_dead and Time.get_ticks_msec() - death_freeze_start_ms >= 500:
    switch_to_death_scene()
```

### 敌人受击

```
# player_damage 是经所有修正后的最终伤害值
# （基础值 + 构筑加成 + skill_2 倍率修饰）
final_player_damage = base_player_damage + build_damage_bonus
# 若 skill_2 激活：final_player_damage *= 2
enemy_hp -= final_player_damage
if enemy_hp <= 0:
    enemy_dead()
```

**变量表**：

| 符号 | 类型 | 范围 | 说明 |
|------|------|------|------|
| base_player_damage | int | 1 | 默认每发子弹伤害 |
| build_damage_bonus | int | 0-N | 构筑系统累加的伤害加成 |
| final_player_damage | int | 1-N | 经所有修正后的最终伤害 |

## Edge Cases

- **无敌帧内被多敌人同时碰撞**：全部忽略——无敌 = 绝对不受伤害。无敌帧期间护盾也不消耗
- **护盾 + 无敌帧同时存在**：护盾先消耗。若护盾完全吸收伤害，不触发无敌帧。若伤害穿透护盾扣减 HP，则触发无敌帧
- **大型敌人（伤害=2）命中 1 层护盾**：护盾吸收 1 点，剩余 1 点扣减 HP。剩余伤害触发无敌帧
- **大型敌人命中护盾=0 且 HP=1**：HP=1 承受 2 点伤害 → HP = -1 → `is_dead = true`。溢出伤害无效
- **HP=1 时大型敌人命中（伤害=2）**：HP 归零死亡——伤害 2 与伤害 1 结果相同（均致死）。溢出伤害不累积
- **血量已满时极限闪避成功（充能≥1）**：不额外增加血量（不溢出），但仍然产生护盾
- **护盾期间受击且护盾完全吸收**：消耗护盾，不扣血量，不触发无敌帧
- **伤害值 > 剩余血量**：血量归零，溢出伤害无效
- **死亡瞬间触发极限闪避成功（充能≥1）**：不恢复血量——死亡优先（`hp > 0` 守卫阻止回血）
- **极限闪避成功（充能=0）**：不恢复血量，无护盾——仅无敌帧
- **极限闪避成功（充能≥1）且玩家已在无敌帧中**：回血正常生效——允许在受击后立即通过闪避回血。这是有意设计的奖励机制
- **护盾过期（3 秒真实时间到）**：护盾归零，无特殊反馈。若在护盾过期瞬间受击，伤害直接作用于 HP
- **中型敌人子弹伤害 vs 接触伤害**：两者均为 `enemy.damage` 值（MVP 中均为 1），统一使用 `incoming_damage`

## Dependencies

- **上游依赖**：闪避系统 C3（无敌状态+极限闪避回血信号）、射击系统 C2（伤害值）、敌人系统 C6（碰撞伤害 1/2 + 接触检测用于极限闪避）
- **下游依赖**：Diegetic UI P2（光环显示）、VFX P1（受击反馈）、音频 F3（音效）
- **循环依赖 C3 ↔ C5**：通过接口解耦——伤害系统读取闪避公共状态，不依赖闪避内部实现

## Tuning Knobs

| 参数 | 默认值 | 安全范围 | 说明 |
|------|-------|---------|------|
| 玩家最大血量 | 3 | 2-5 | 太高中无敌群无压力，太低一击必杀无容错 |
| 无敌帧时长 | 500ms | 300-800ms | 真实时间。太短连续受击，太长无敌期过长 |
| 极限闪避回血量 | 1 | 1-2 | 仅极限闪避（充能≥1）恢复点数 |
| 护盾持续时间 | 3s | 2-5s | 真实时间（`Time.get_ticks_msec()`）。极限闪避额外护盾 |
| 玩家基础伤害 | 1 | 1-3 | 每发子弹伤害（构筑可提升） |
| 极限闪避检测距离 | 40px | 20-50px | 所有攻击类型——子弹+接触+近战 |

## Acceptance Criteria

### 玩家受击与死亡

- **AC1**：**GIVEN** 玩家 HP=3，**WHEN** 小型敌人（伤害=1）命中，**THEN** HP=2，触发 500ms 无敌帧
- **AC2**：**GIVEN** 玩家 HP=1，**WHEN** 任意敌人命中，**THEN** HP=0，`is_dead=true`，战斗冻结（所有敌人 AI + 子弹 + 玩家输入停止，VFX/摄像机继续），500±50ms 真实时间后切换到死亡结算场景
- **AC3**：**GIVEN** 玩家 HP=3，**WHEN** 大型敌人（伤害=2）命中，**THEN** HP=1（扣 2 点），触发无敌帧
- **AC4**：**GIVEN** 玩家 HP=1，**WHEN** 大型敌人（伤害=2）命中，**THEN** HP=0 死亡（溢出无效）

### 无敌帧

- **AC5**：**GIVEN** 玩家处于无敌帧（500ms 内），**WHEN** 任意敌人攻击，**THEN** HP 不变，护盾不消耗
- **AC6**：**GIVEN** 玩家无敌帧中且 `Engine.time_scale = 0.2`，**WHEN** 500ms 真实时间后，**THEN** 无敌帧解除（不受时间缩放影响）

### 回血与护盾

- **AC7**：**GIVEN** 玩家 HP=2 且充能≥1，**WHEN** 极限闪避成功，**THEN** HP=3 + 获得 1 次护盾（持续 3s 真实时间）
- **AC8**：**GIVEN** 玩家 HP=2 且充能≥1，**WHEN** 普通闪避成功，**THEN** HP 保持 2（普通闪避不回血）
- **AC9**：**GIVEN** 玩家 HP=2 且充能=0，**WHEN** 极限闪避成功（仅无敌帧），**THEN** HP 保持 2，无护盾
- **AC10**：**GIVEN** 玩家 HP=3（已满）且充能≥1，**WHEN** 极限闪避成功，**THEN** HP 保持 3（不溢出），但仍获得 1 次护盾
- **AC11**：**GIVEN** 玩家 HP=0（已死亡），**WHEN** 同帧极限闪避成功，**THEN** HP 保持 0（死亡优先，不回血）

### 护盾行为

- **AC12**：**GIVEN** 玩家有 1 次护盾，**WHEN** 小型敌人（伤害=1）命中，**THEN** 护盾消耗（归零），HP 不变，不触发无敌帧
- **AC13**：**GIVEN** 玩家有 1 次护盾，**WHEN** 大型敌人（伤害=2）命中，**THEN** 护盾归零，HP-1，触发无敌帧
- **AC14**：**GIVEN** 玩家有护盾且处于无敌帧中，**WHEN** 敌人攻击，**THEN** 护盾不消耗（无敌帧优先）
- **AC15**：**GIVEN** 极限闪避后获得护盾，**WHEN** 3s 真实时间过去且未受击，**THEN** 护盾过期归零

### 敌人受击

- **AC16**：**GIVEN** 小型敌人 HP=1，**WHEN** 1 发子弹命中，**THEN** 敌人死亡
- **AC17**：**GIVEN** 中型敌人 HP=3，**WHEN** 2 发子弹命中，**THEN** 敌人未死亡（HP=1）
- **AC18**：**GIVEN** 中型敌人 HP=3，**WHEN** 3 发子弹命中，**THEN** 敌人死亡
- **AC19**：**GIVEN** 大型敌人 HP=8，**WHEN** 8 发子弹命中，**THEN** 敌人死亡
- **AC20**：**GIVEN** 玩家有 +1 构筑伤害加成，**WHEN** 命中中型敌人 HP=3，**THEN** 2 发子弹击杀（伤害=2/发）

## Open Questions

- **构筑是否增加最大血量**：是否有升级选项增加血量上限？MVP 不涉及，预留 `max_hp_bonus` 变量
- **敌人伤害是否区分类型**：已决定——小型 1、中型 1、大型 2（见敌人系统 GDD）。详见 Formulas 节 `incoming_damage`
- **是否有环境伤害**：化工园区是否有化学品区域造成伤害？MVP 不做
- **连锁无敌帧是否需要安全阀**：理论上可通过完美闪避链接近永久无敌。MVP 不设限制——若 playtest 暴露此问题，加 `perfect_dodge_iframe_cooldown` 参数（默认 0ms，安全范围 0-2000ms）
- **中型敌人子弹伤害是否可能不同于接触伤害**：MVP 中两者相同（均为 1），通过 `enemy.damage` 统一取值。若未来分离，加 `enemy.projectile_damage` 字段
