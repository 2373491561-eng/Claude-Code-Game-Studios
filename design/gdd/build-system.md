# 构筑系统

> **Status**: Approved
> **Author**: user + agents
> **Last Updated**: 2026-05-07
> **Implements Pillar**: 构筑决定命运（P3）— 每局的升级选择塑造独特的战斗风格

## Overview

构筑系统是《裂隙反应》的 Roguelike 灵魂——每波结束后，3 张升级卡片从底部滑入，玩家选择 1 张。12 个基础升级选项分布在随机池中，每局只能拿到其中一部分——今天的你可能是冷却流（技能 1 几乎零 CD），明天可能是闪避流（极限闪避窗口更宽、回血更多）。构筑选择不是"哪个更强"——而是"这次我要成为什么样的战士"。每个构筑方向有完整的视觉方言（美术圣经 C3 原则）：颜色 + 粒子形状 + 弹道 + 命中特效，四要素统一。

## Player Fantasy

构筑追求的幻想是"这一次，我是不同的战士"。上一局你是电光蓝冲击波专家——技能 1 几乎无冷却，全场粒子爆炸。这一局你是闪避大师——极限闪避窗口从 100ms 扩到 150ms，每次闪避回满血。下一局你是子弹风暴——射速翻倍、弹道分裂。拿到的升级不是"数值增长"，而是"风格分化"——当你看到自己的弹道变成电光蓝、命中粒子变成六角形，你知道"这是我的构筑"。

## Detailed Design

### Core Rules

**升级池**：12 个基础升级选项。每波结束后从池中随机抽取 3 个，展示给玩家。玩家选择 1 个。同一 Run 中已选择的升级不会再次出现。

**升级分类**：

| 类别 | 数量 | 示例 |
|------|:---:|------|
| 武器强化 | 3 | 射速 +25%、伤害 +1、弹道穿透（命中后继续飞行） |
| 技能强化 | 3 | 技能 1 CD -5s、技能 1 范围 +30%、技能 2 伤害翻倍 |
| 闪避强化 | 3 | 闪避充能 +1、充能恢复加速 50%、极限闪避窗口 +50ms |
| 生存强化 | 2 | 最大血量 +1、护盾持续时间 +2s |
| 特殊 | 1 | 闪避恢复技能 2（普通闪避也能触发 skill_2，但窗口只有 250ms） |

**构筑方向**（视觉方言示例）：

| 方向 | 主色调 | 粒子形状 | 弹道风格 | 命中特效 |
|------|--------|---------|---------|---------|
| 火焰 | 炽橙 | 圆形火花 | 抛物线弹道 | 橙红爆炸 |
| 雷电 | 电光蓝 | 六角形碎片 | 直线弹道 | 电弧跳跃 |
| 虚空 | 紫红 | 三角碎片 | 慢速穿透 | 紫色腐蚀 |

所有升级必须四要素统一——例如火焰方向的升级使用炽橙色、圆形粒子、抛物线弹道、橙红命中。切换方向时视觉过渡自然。

**升级卡片 UI**：每张卡片 180×240px，像素边框+厚角。图标区（64×64px 像素符号）+ 名称 + 描述。选中后飞入屏幕中心（吸收动画）。

### States and Transitions

| 状态 | 说明 |
|------|------|
| **展示** | 3 卡从底部滑入，等待选择 |
| **选中** | 选中卡放大+闪白，飞入吸收 |
| **构筑更新** | 效果立即生效——下一波开始应用新属性 |

### Interactions with Other Systems

| 系统 | 接口 |
|------|------|
| 波次管理（F6） | 波次结束 → 触发构筑选择 |
| 射击系统（C2） | 武器强化 → 修改射速/伤害 |
| 技能系统（C4） | 技能强化 → 修改 CD/范围 |
| 闪避系统（C3） | 闪避强化 → 修改充能/窗口 |
| 伤害系统（C5） | 生存强化 → 修改最大血量 |
| 升级卡片 UI（P4） | 卡片展示+选择交互 |
| VFX（P1） | 构筑方向 → 视觉方言切换 |

## Formulas

### 随机抽取

`pool = all_upgrades - already_chosen`
`drawn = random.sample(pool, min(3, len(pool)))`

如果剩余 < 3 张，抽取全部剩余。池子耗尽时（Run 极长），所有选项重新洗入。

## Edge Cases

- **选项池 < 3**（Run 后期，已选 10+ 升级）：抽取所有剩余——如果只剩 2 张就展示 2 张
- **选项池耗尽**（Run 极长，12 张全选完）：所有选项重新洗入池子——可以重复选择同一升级（效果叠加或刷新）
- **同一波次展示 3 张同类别卡片**：随机抽取不保证类别多样性——如果全是武器强化，这是"Roguelike 的诚实"
- **构筑方向切换**（火→雷）：新选择的升级方向视觉覆盖旧方向——当前 Run 可以有混合视觉，但至少在 2 个维度上有区分（C3 原则）

## Dependencies

- **上游依赖**：波次管理 F6（触发时机）
- **下游依赖**：射击 C2、技能 C4、闪避 C3、伤害 C5（属性修改）、升级卡片 UI P4（展示）、VFX P1（视觉方言）
- **波次管理 F6 已有 GDD** ✅

## Tuning Knobs

| 参数 | 默认值 | 安全范围 | 说明 |
|------|-------|---------|------|
| 总升级数 | 12 | 8-16 | 太少缺乏多样性，太多平衡困难 |
| 每波展示数 | 3 | 2-4 | 太少选择感弱，太多决策疲劳 |
| 射速加成 | +25% | 15-50% | 累积效果需考虑叠加 |

## Acceptance Criteria

- **GIVEN** 第 1 波清完，**WHEN** 波次过渡，**THEN** 3 张升级卡片从底部滑入
- **GIVEN** 3 张卡片展示中，**WHEN** 玩家点击 1 张，**THEN** 该升级效果立即生效
- **GIVEN** 玩家选择"射速 +25%"，**WHEN** 下一波开始，**THEN** 射击间隔缩短 25%
- **GIVEN** 玩家选择"闪避充能 +1"，**WHEN** 下一波开始，**THEN** 闪避最大充能从 3 变为 4
- **GIVEN** Run 中已选 10 个升级，**WHEN** 下一波过渡，**THEN** 展示剩余 2 张（池子 < 3）
- **GIVEN** 玩家选择火焰方向升级，**WHEN** 下一波射击，**THEN** 弹道和命中粒子使用炽橙+圆形风格

## Open Questions

- **升级是否可叠加**：同一升级被选多次——效果叠加还是刷新？建议叠加（数值有上限）
- **是否有稀有度**：美术圣经提到卡片右上角可能有稀有度角标——MVP 不做，所有升级等价
- **是否有负面选项**："伤害 +50% 但移速 -20%"这类取舍——MVP 不做，全部为正面
