# 音频系统

> **Status**: Approved
> **Author**: user + agents
> **Last Updated**: 2026-05-07
> **Implements Pillar**: 每一枪都要有感觉（P2）— 音效是反馈三要素之一

## Overview

音频系统是《裂隙反应》的听觉引擎——它管理从菜单背景音乐的冷蓝期待、到战斗中每一次射击和闪避的音效反馈、到技能爆发时的音频冲击波、再到死亡结算时暖暮余烬的旋律。它在幕后运行——跨场景保持背景音乐的连续性、在技能爆发时压低其他声音（ducking）、在时间缩放中同步音高——让听觉和视觉、触觉（震动）三位一体，组成支柱2"每一枪都要有感觉"的完整反馈链。

## Player Fantasy

音频系统追求的幻想是"耳中的战场"。闭着眼睛，你也能听出发生了什么——一声枪响后的命中确认音、极限闪避时的冷冽时间音效、技能满充能的上升音高预警、释放时低频冲击波的压迫感。声音不只是装饰——它是信息。充能球满了，你听到它；敌人从背后接近，你听到它；下一波即将到来，你听到它。

## Detailed Design

### Core Rules

**音频总线结构**：

```
Master
├── BGM（背景音乐）
├── SFX（音效）
│   ├── Weapon（武器射击）
│   ├── Impact（命中/受击）
│   ├── Dodge（闪避）
│   ├── Skill（技能爆发）
│   └── Enemy（敌人音效）
└── UI（界面音效）
```

**音频事件表**：

| 事件 | 总线 | 优先级 | 说明 |
|------|------|:---:|------|
| 普通射击 | SFX/Weapon | 中 | 短促枪声，按射速频率触发 |
| 命中敌人 | SFX/Impact | 中 | 击中确认音+敌人受击声 |
| 普通闪避 | SFX/Dodge | 高 | 快速位移音效 |
| 极限闪避 | SFX/Dodge | 最高 | 冷冽时间音效+音高下降（时间缩放同步） |
| 技能充能满 | SFX/Skill | 高 | 上升音高预警 |
| 技能爆发 | SFX/Skill | 最高 | 低频冲击+电光蓝音色+橙红爆裂尾音 |
| 敌人死亡 | SFX/Enemy | 低 | 碎裂/爆炸音 |
| 波次过渡 | UI | 中 | 卡片出现音 |
| UI 交互 | UI | 低 | 点击/悬停音 |

**背景音乐**：

| 场景/状态 | 音乐特征 | 说明 |
|------|------|------|
| 主菜单 | 冷蓝工业氛围、低音脉冲 | 期待感 |
| 常态战斗 | 紧凑鼓点+低音贝斯、渐强 | 压迫积累 |
| 技能爆发时 | BGM短暂闪避（duck -12dB） | 让音效"说话" |
| 死亡结算 | 暖暮旋律、逐渐淡出 | 余烬感 |

**Ducking 规则**（与技能系统 GDD v3 对齐）：技能爆发时触发全面 Ducking——Attack 50ms（快速压低），Hold 450ms（覆盖 0.5s 爆发动画），Release 500ms（ease-out 缓慢恢复）。Ducking 使用真实时间（`Tween.set_ignore_time_scale(true)`），不受时间缩放影响。Ducking 范围：BGM -12dB，SFX/Weapon -9dB，SFX/Dodge -6dB，SFX/Impact -6dB，SFX/Enemy -9dB，UI -6dB。SFX/Skill 0dB（不 Duck——爆发是主角）。

**时间缩放音效**：极限闪避 `time_scale=0.2` 时，世界音效（Weapon/Impact/Enemy 总线）音高降低 2 个八度（通过 `AudioStreamPlayer.pitch_scale` 显式设置，`Engine.time_scale` 不影响 AudioServer）。技能爆发（SFX/Skill）以真实时间正常音高播放——爆发是"释放"瞬间，不应被时间缩放压制。这与技能系统 GDD v3 对齐。

### States and Transitions

| 状态 | 说明 |
|------|------|
| 菜单 | BGM 菜单音轨播放 |
| 战斗 | 菜单 BGM 淡出 → 战斗 BGM 淡入。战斗 SFX 激活 |
| 暂停 | 所有音频暂停（包括 BGM） |
| 死亡 | 战斗 BGM 停止 → 死亡音轨淡入 |

### Interactions with Other Systems

| 系统 | 接口 |
|------|------|
| 场景管理（F2） | 场景切换触发 BGM 切换 |
| 射击系统（C2） | 射击/命中事件 → 音效触发 |
| 闪避系统（C3） | 普通/极限闪避事件 → 音效+时间音高 |
| 技能系统（C4） | 充能满/爆发事件 → 音效+Ducking |
| 敌人系统（C6） | 敌人死亡/出现事件 → 音效 |
| 设置系统（PL2） | 音量控制（Master/BGM/SFX 三通道） |

## Formulas

音频系统不涉及数学公式。音量和 Ducking 参数见 Tuning Knobs。

## Edge Cases

- **同一帧触发多个同优先级音效**：最多同时播放 8 个，超过则终止最早触发者
- **极限闪避 + 技能爆发同时**：闪避音效先触发（时间缩放），爆发音效等待时间恢复后释放
- **连续快速射击**（高射速）：不重复触发独立音效——使用循环音轨，射击时开启、松开时停止
- **BGM 切换被快速场景切换打断**：BGM 交叉淡入淡出有最小持续时间（500ms），在此时间内忽略额外的切换请求

## Dependencies

- **上游依赖**：无（基础层）
- **下游系统**：所有音效事件由游戏系统触发
- **Autoload**：AudioManager 跨场景运行

## Tuning Knobs

| 参数 | 默认值 | 范围 | 说明 |
|------|-------|------|------|
| BGM 音量 | 0.7 | 0-1.0 | 主音量乘数 |
| SFX 音量 | 0.85 | 0-1.0 | 音效需要比 BGM 稍高 |
| Ducking BGM 衰减 | -12dB | -6~-18dB | 爆发时 BGM 降低幅度 |
| Ducking 持续时间 | 0.5s | 0.3-1.0s | 恢复前的时间 |
| 最大同时 SFX 数 | 8 | 4-16 | 超过此数终止最早的 |
| BGM 交叉淡入淡出 | 1.0s | 0.5-2.0s | 场景切换时 BGM 过渡 |

## Visual/Audio Requirements

音频系统本身就是音频需求的集中定义——音效事件表、BGM 规格、Ducking 规则均已在本 GDD 的 Detailed Design 中定义。

## UI Requirements

音频系统不拥有 UI。音量控制滑块属于设置系统（PL2）负责。

## Acceptance Criteria

- **GIVEN** 玩家在主菜单，**WHEN** 游戏启动，**THEN** 菜单 BGM 播放
- **GIVEN** 玩家点击"开始"，**WHEN** 加载战斗场景，**THEN** 菜单 BGM 1s 内淡出、战斗 BGM 淡入
- **GIVEN** 玩家按下射击键，**WHEN** 子弹发出，**THEN** 射击音效在 50ms 内播放
- **GIVEN** 子弹命中敌人，**WHEN** 碰撞发生，**THEN** 命中确认音+敌人受击声播放
- **GIVEN** 玩家触发极限闪避，**WHEN** 闪避成功，**THEN** 冷冽时间音效播放+所有音高下降
- **GIVEN** 玩家释放技能爆发，**WHEN** 技能触发，**THEN** BGM duck -12dB + 爆发音效优先播放 + 0.5s 后恢复
- **GIVEN** 玩家按下 Esc 暂停，**WHEN** 游戏暂停，**THEN** 所有音频暂停
- **GIVEN** 玩家在设置中调整音量，**WHEN** 拖动滑块，**THEN** 对应通道音量实时变化

## Open Questions

- **音效资源来源**：自录音效 vs 购买音效包 vs 合成生成？MVP 建议使用免版税音效包
- **战斗 BGM 是否需要分层**：不同波次紧张程度是否需要不同音乐层？（如波次 1-3 只有鼓点，4-7 加入贝斯，8+ 加入失真合成器）
- **3D 定位音频**：2D 俯视角是否需要基于距离/方向的音量衰减？MVP 不建议——增加复杂度，收益有限
