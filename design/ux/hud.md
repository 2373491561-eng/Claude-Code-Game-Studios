## Overview

HUD 是战斗中的辅助信息层，显示波次计数、击杀数、武器图标和技能冷却。所有信息以 50% 不透明度常驻，变化时升至 85%，技能释放瞬间降至 20%（视觉独占权）。Diegetic UI（血量光环、充能球、闪避光点）直接渲染在角色身上，由 Diegetic UI 系统单独管理，不在此 HUD 范围内。

## 不透明度策略

| 状态 | 不透明度 | 过渡时间 | 触发条件 |
|------|:------:|:------:|------|
| **常态** | 50% | — | 默认 |
| **信息变化** | 85% | 0.3s ease-out | 波次+1、击杀+1、技能冷却归零 |
| **释放瞬间** | 20% | 0.1s ease-in | 技能1释放前0.5s |
| **恢复** | 50% | 0.5s ease-out | 释放动画结束后 |

所有不透明度过渡使用 `Tween`。`Tween.set_ignore_time_scale(true)` 确保不透明度不受时间缩放影响。

## 元素行为

### 波次计数 "WAVE X"

- 字体：8px 像素等宽（art bible §7）
- 颜色：纯白 `#FFFFFF`
- 波次数字变化时：数字放大 120% → 弹回 100%（0.2s ease-out）+ 短暂亮闪（白→电光蓝→白，0.3s）
- 连接 `EventBus.wave_start` 信号

### 击杀计数 "× N"

- 字体：8px 像素等宽
- 颜色：纯白
- 击杀+1时：数字闪白 2 帧（~8ms at 240fps），然后恢复
- 连接 `EventBus.enemy_killed` 信号

### 武器图标

- 16×16px 像素图标（当前构筑方向色）
- 常态静态，射击时图标微缩（95%）+ 回弹（0.1s）
- 连接 `EventBus.bullet_hit` / 射击状态

### 技能1冷却

- 16×16px 技能图标 + 右侧 8px 数字（剩余秒数，四舍五入到 0.1s）
- 冷却中：图标灰蓝 + 数字显示
- 就绪：图标电光蓝+橙红脉动 + 数字隐藏（显示 "READY"）
- 释放中：图标全白闪 + 数字替换为动画条（0.5s 递减）
- 冷却数字变化通过 `EventBus` 或直接读取 `SkillSystem.cooldown_remaining`

### 技能2状态

- 16×16px 图标
- 未激活：灰蓝 30% 不透明度
- 窗口开放（极限闪避后 500ms）：图标亮蓝 + 边框脉冲 + 500ms 倒计时环
- 已消费：图标白闪 → 灰蓝
- 窗口过期：图标直接回到灰蓝（无动画）
- 连接 `EventBus.skill_2_triggered` / `EventBus.dodge_perfect`

## 交互规则

- HUD 不接收输入 — 所有元素 `mouse_filter = MOUSE_FILTER_IGNORE`
- 暂停时（Esc）：HUD 保留显示但冻结所有动画
- 波次过渡时：HUD 保留显示，不透明度随暗角变化（50% → 30%，与暗角同步）

---

## 与 Diegetic UI 的分工

| 信息 | 位置 | 负责系统 |
|------|------|---------|
| 血量 | 角色脚下光环 | Diegetic UI |
| 闪避充能 | 角色周围光点 | Diegetic UI |
| 技能充能状态 | 角色背后充能球 | Diegetic UI |
| 波次/击杀 | 屏幕顶部 | **HUD** |
| 武器/技能冷却 | 屏幕底部 | **HUD** |

规则：角色身上 → Diegetic UI。屏幕边缘 → HUD。两者不互相覆盖。

---

## 无障碍

- 波次和击杀数字：8px 字体在 960×540 下约 3.2mm（24" 1080p 显示器），满足 accessibility-requirements.md Basic 等级的"核心 HUD 信息高度 ≥ 3mm"要求
- 冷却数字：仅作为充能球（Diegetic UI，颜色+脉动双重编码）的辅助信息 — 非唯一信息源
- 所有状态变化都有非颜色备份信号（数字变化、大小变化、脉冲）

## Acceptance Criteria

- **GIVEN** 战斗中波次=5，**WHEN** 查看 HUD，**THEN** 左上角显示 "WAVE 5"（50% 不透明度）
- **GIVEN** 击杀 47 个敌人，**WHEN** 查看 HUD，**THEN** 右上角显示 "× 47"
- **GIVEN** 新击杀，**WHEN** 计数变化，**THEN** 不透明度升至 85%，0.5s 后回落至 50%
- **GIVEN** 技能1冷却中（剩余 8.3s），**WHEN** 查看底部，**THEN** 显示技能图标 + "8.3"
- **GIVEN** 技能1就绪，**WHEN** 查看底部，**THEN** 图标电光蓝+橙红脉动 + "READY"
- **GIVEN** 技能爆发释放中，**WHEN** 前 0.5s，**THEN** HUD 不透明度降至 20%
- **GIVEN** 按下 Esc 暂停，**WHEN** 游戏暂停，**THEN** HUD 保留显示但冻结动画
- **GIVEN** 极限闪避成功，**WHEN** skill_2 窗口打开，**THEN** 技能2图标亮蓝+脉冲+倒计时环
