## Prototype Report: 闪避系统

### Hypothesis
闪避充能制 + 距离判定极限闪避 + 时间缩放反馈链是可行的核心机制。

### Approach
Godot 4.6.2 最小原型，代码动态创建所有视觉元素，无外部资产。

### Result
- 普通闪避（Shift/右键）：消耗1充能、位移100px、300ms无敌，手感成立
- 极限闪避（子弹 40px 内闪避）：不耗充能、时间缩放 0.2x、蓝屏滤镜，触发直观
- 充能管理（3次/3秒恢复）：产生有意义的资源决策
- 颜色反馈：绿=正常、蓝=极限闪避、橙=被击中、白闪=无敌帧

### 调优后参数
| 参数 | 值 |
|------|-----|
| 极限闪避判定距离 | 40px（从 16px 放宽） |
| 闪避位移 | 100px / 300ms |
| 充能 | 3次 / 3秒恢复 |
| 无敌 | 仅闪避期间（300ms） |

### Recommendation: PROCEED

核心手感可行。极限闪避的距离判定比时间窗口判定更直观、更易测试。

### If Proceeding
- 调整设计文档 `design/gdd/dodge-system.md` 的极限闪避判定方式：从时间窗口改为距离判定
- 距离判定值 40px 作为默认，可调范围 20-60px
- 添加音效、完整 Diegetic UI、与技能系统联动

### Lessons Learned
- 距离判定比时间窗口更容易理解和测试
- 闪避后无敌仅限闪避期间（而非闪避后延长无敌）让操作更有紧张感
- 颜色反馈（蓝/橙/绿）是快速确认状态的最有效手段
